# Критерии severity

Severity — о влиянии на пользователя и бизнес, не о сложности исправления. Сомнение между двумя уровнями → выбрать нижний и указать в `hypothesis`, что может быть выше. `info` — заметка без дефекта (не публикуется как issue, если пользователь не попросил).

| Уровень | Определение | Примеры |
|---------|-------------|---------|
| **Critical** | Ключевая функция недоступна большинству; потеря/утечка данных; угроза безопасности, видимая пассивно; сайт/раздел не открывается | главная отдаёт 500; форма входа не работает ни в одном браузере; токен/ключ API в открытом JS; персональные данные других пользователей видны на странице; mixed content на странице оплаты; карта — основа сервиса — не загружается |
| **High** | Ключевая функция сломана для заметной группы (браузер, устройство, сценарий) или работает неправильно; блокирующая проблема доступности | поиск выдаёт пустой результат на корректный запрос; в Safari/WebKit не открывается меню; на 375 px кнопка «Далее» за краем экрана; клавиатурой невозможно пройти основной сценарий (WCAG 2.1.1); фильтр сбрасывается при «Назад» и теряет ввод; LCP > 4 с на мобильном на главной; нет HTTPS-редиректа |
| **Medium** | Функция работает, но с заметной ошибкой или неудобством; есть обходной путь; нарушение WCAG AA, не блокирующее сценарий | битые внутренние ссылки; ошибки JS в консоли без видимого эффекта; контраст текста 3.5:1; нет видимого фокуса; состояние фильтров не попадает в URL (нельзя поделиться); нет HSTS; тач-зона 32×32; CLS 0.15; дубли title на разных страницах |
| **Low** | Косметика, мелкие несогласованности, улучшения | разные отступы у однотипных карточек; опечатка; нет `meta description`; отсутствует `Referrer-Policy`; иконка без подписи, но с понятным контекстом; лишние 200 КБ изображений |
| **Info** | Наблюдение, предложение, вопрос | user story; идея функции; «ссылка ведёт на X — не проверялось» |

## Повышающие и понижающие факторы
- +1 уровень: проблема на главной/в главном сценарии; затрагивает все страницы шаблона; регрессия (`REGRESSION`).
- −1 уровень: только на редкой ширине/браузере при наличии обходного пути; только в deep-граничном вводе.
- Доступность: нарушение уровня A, блокирующее задачу → High; AA → Medium; best-practice → Low.
- Производительность (мобильная, главная): LCP > 4 с или CLS > 0.25 → High; LCP 2.5–4 с, CLS 0.1–0.25, INP > 200 мс → Medium.
- Пассивная безопасность: нет CSP/X-Content-Type-Options → Low; нет HSTS → Medium; секреты/PD в открытом виде → Critical.

Для чужого репозитория — привести к их шкале (метки `priority:*`, `P0–P3`, поле формы «Severity»), соответствие указать в черновике.
