# Матрица глубины

| Параметр | smoke | standard | deep |
|----------|-------|----------|------|
| Страницы | ключевые: главная, 3–7 основных разделов/шаблонов, ключевой сценарий | все найденные до лимита (`scope.page_limit`, спросить; по умолчанию 50) | все найденные (с разумным потолком 300; превышение — спросить) |
| Шаблоны страниц | по 1 представителю | по 2–3 представителя каждого шаблона | все |
| Ширины | 1440 (десктоп), 375 (мобильная) | 375, 768, 1440 | 360, 768, 1024, 1440, 1920 (+375 для iOS-сценариев) |
| Браузеры | Chromium | Chromium, WebKit | Chromium, Firefox, WebKit |
| Сценарии | критические (главный путь пользователя, навигация, поиск, ключевая форма без отправки) | все основные пользовательские задачи | + граничные случаи, прерывания, гонки |
| Чек-листы | разделы «Smoke» | «Smoke» + «Standard» | все разделы |
| a11y | axe на ключевых страницах + клавиатура на главной | axe на всех + клавиатура по шаблонам | полный WCAG 2.2 AA: axe, клавиатура, 200% zoom, reduced motion, скринридер-структура |
| performance | Lighthouse mobile на главной | Lighthouse mobile+desktop по шаблонам | mobile+desktop на всех шаблонах, анализ ресурсов и кэша |
| product | — (только явные идеи) | список предложений | user stories + предложения по редизайну с приоритетом |
| Скриншоты | на каждую находку | + эталонные по шаблонам | + на всех ширинах |
| Ориентировочное время | 15–40 мин | 1–3 ч | 3–8 ч |

Если браузер из матрицы недоступен (`env.json → browsers`), он пропускается с пометкой в отчёте.
Пользователь может переопределить ширины и браузеры (вопрос 7 опроса) — тогда `devices` в run-config главнее матрицы.

## Связь с направлениями
- Направление включено, но для глубины пункт чек-листа не предусмотрен → не выполнять.
- `responsive-cross-browser` при smoke = только две ширины в Chromium, без сравнения браузеров.
- `product` при smoke пропускается целиком, если пользователь явно не выбрал его.
- `content-i18n` при smoke — ключевые экраны на основном языке; standard — все шаблоны; deep — все языки из переключателя (если смена языка не запрещена).
