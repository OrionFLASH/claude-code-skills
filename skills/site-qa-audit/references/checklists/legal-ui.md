# legal-ui — юридически значимые элементы интерфейса

Направление: `legal-ui` · Инструменты: `node/legal_guest.js` (гость в чистом профиле), `url_guard.py nav --read-only` / `guard.js` `readOnly` (страницы входа, регистрации, покупки — только чтение), `shot.js --locales`, Playwright MCP для просмотра · Усилители: нет

## Цель
Зафиксировать **факты**, которые важны для правовой оценки сайта: что сайт сохраняет у нового посетителя до его согласия, какие сторонние сервисы вызываются, есть ли баннер cookie и согласие на обработку данных, какие документы опубликованы и где, видны ли сведения об операторе и возрастная маркировка. Скил **не даёт юридических заключений**: нормы права упоминаются только как «возможно применимо» и всегда с пометкой «проверить юристом».

## Правило для правовых утверждений (обязательно)
- В находке — наблюдаемый факт («до любого действия ставится 7 cookie, из них 2 — третьих сторон: …»), а не вывод («нарушает закон»).
- Если в находке названы нормы права, санкции или финансовые последствия: поле `legal: {claims_law: true, norms: [...], jurisdictions: [...]}`; **вторая проверка другим исполнителем** (отдельный субагент или оркестратор, не тот, кто нашёл) — `recheck.py legal <RUN_DIR> --id F-NNN --by "<кто, по каким источникам>" --result confirmed|corrected|rejected`; в тексте issue — «Возможно применимые нормы … требуется проверка юристом» (`render_draft.py` добавляет сам). Без второй проверки находка не публикуется (`recheck.py gate`, сводная таблица).
- Не цитировать нормы по памяти как точные: номер статьи, редакцию и применимость к сайту проверяет второй исполнитель по первоисточнику (официальный текст закона), иначе — только общее описание требования.

## Безопасность в этом направлении
- Страницы входа, регистрации, оплаты, доната — **только чтение**: `url_guard.py nav <URL> --read-only --log <RUN_DIR>/logs/read-only.jsonl` или `guardedPage(…, { readOnly: true })`; ничего не нажимать и не отправлять, никаких `curl` мимо guard (`safety-rules.md` §3.13).
- Кнопки баннера («Принять», «Отклонить») не нажимать без разрешения: согласие от имени пользователя — запрет B5. Их тексты фиксируются (`banner.buttons`).
- Скриншоты форм входа без введённых данных; персональные данные — маскировать.

## Smoke
- [ ] `legal.guest-storage` — `node <SKILL_DIR>/scripts/node/legal_guest.js <URL> --rules <RUN_DIR>/rules.json --wait 7000 --out <RUN_DIR>/raw/legal-guest.json`: cookie и ключи localStorage/sessionStorage **сразу после загрузки** (`cookies.t0`) и **через N секунд без действий** (`cookies.tN`), у каждой cookie — сторона (`first`/`third`), срок, `httpOnly`, `secure`. Значения cookie не сохраняются.
- [ ] `legal.third-parties` — сторонние хосты до согласия (`hosts.third`): аналитика, реклама, шрифты, CDN, виджеты; кто из них ставит cookie.
- [ ] `legal.cookie-banner` — баннер есть / нет (`banner.present`), его текст и кнопки (`banner.buttons`): есть ли отказ рядом с согласием, ставятся ли cookie до выбора.
- [ ] `legal.documents` — ссылки на документы (`links`): политика конфиденциальности / обработки персональных данных, пользовательское соглашение, оферта, правила, политика cookie, Impressum; открыть каждую под guard (только чтение) и проверить, что страница существует и на языке интерфейса.

## Standard (в дополнение к smoke)
- [ ] `legal.signup-consent` — страницы входа и регистрации (`--read-only`): есть ли согласие на обработку данных и ссылка на политику рядом с кнопкой, отмечен ли флажок согласия заранее (тексты флажков и кнопок, без нажатия).
- [ ] `legal.operator-info` — сведения об операторе/владельце (`operator`: ИНН, ОГРН, адрес, VAT, Impressum) — где и на каких языках.
- [ ] `legal.age-mark` — возрастная маркировка (`age`: «0+», «12+», «16+», «18+») — есть ли и где.
- [ ] `legal.paid-terms` — страницы покупки и подписки (`--read-only`): цена, период, автопродление, ссылка на условия возврата — до перехода к оплате.
- [ ] `legal.locales` — то же для всех языков сайта: `legal_guest.js --locales ru-RU,en-US,de-DE,fr-FR,es-ES,…` — баннер и документы есть на каждом языке, а не только на основном.

## Deep
- [ ] `legal.no-automation` — повтор `legal_guest.js` с `--cdp http://127.0.0.1:9222` (новый пустой контекст в обычном Chrome пользователя): в автоматизированном браузере `navigator.webdriver = true`, и часть счётчиков (например, Яндекс.Метрика) не ставит cookie — без этого прогона их можно не увидеть. В результате без `--cdp` есть пометка `note`.
- [ ] `legal.consent-respected` — после «Отклонить» (только с разрешения пользователя на это действие) не появляются cookie аналитики/рекламы: сравнить `cookies.tN` до и после.

## Где искать требования (только как ориентир, проверка — юристом)
| Юрисдикция | На что обычно смотрят |
|---|---|
| Россия | согласие на обработку персональных данных и политика оператора (закон о персональных данных), сведения о возрастной маркировке информационной продукции, маркировка рекламы |
| ЕС | предварительное согласие на необязательные cookie, отказ не сложнее согласия, сведения о контролёре данных, Impressum (Германия, Австрия) |
| США (Калифорния) | ссылка «Do Not Sell or Share My Personal Information» при продаже/передаче данных |
Таблица — подсказка, что проверить, а не утверждение о применимости. В находку нормы попадают только по правилу выше.

## Типовые находки и severity
| Пример | Severity |
|---|---|
| Cookie аналитики/рекламы третьих сторон ставятся до согласия, баннера нет | medium (вывод о нарушении — после проверки юристом) |
| Нет ссылки на политику обработки данных на странице регистрации | medium |
| Документ по ссылке не открывается (404) | medium |
| Баннер только на одном языке из нескольких | low |
| Нет возрастной маркировки | low / info |
