# visual-ui — Визуальная часть и UI

Направление: `visual-ui` · Инструменты: Playwright MCP (`browser_take_screenshot`, `browser_evaluate`, `browser_hover`, `browser_emulate_media`), `node/a11y.js` (контраст) · Усилители: `ui-audit-redesign`, `ux-design-principles`, `laws-of-ux`, browser-devtools `design-qa` (если включён)

## Цель
Оценить визуальную целостность: палитру, контраст, типографику, отступы, сетку, единообразие компонентов и их состояний, темы и иконки.

## Безопасность в этом направлении
- Направление в основном «смотрит»: hover и focus безопасны. Состояние `active` проверяется нажатием только на безопасных элементах (по `url_guard`).
- Переключение темы на сайте (если это настройка аккаунта) — только для неавторизованной сессии или через `browser_emulate_media`, без сохранения в боевом профиле.

## Полезные снимки через `browser_evaluate`
- Размер тач-зон: `() => [...document.querySelectorAll('a,button,input,select,textarea,[role=button],[onclick]')].filter(e => e.offsetParent).map(e => {const r = e.getBoundingClientRect(); return {t: (e.innerText || e.getAttribute('aria-label') || e.name || '').slice(0, 30), w: Math.round(r.width), h: Math.round(r.height)}}).filter(x => x.w < 44 || x.h < 44)`
- Набор шрифтов и размеров: `() => [...new Set([...document.querySelectorAll('body *')].slice(0, 3000).map(e => {const s = getComputedStyle(e); return s.fontFamily.split(',')[0] + ' ' + s.fontSize + ' ' + s.fontWeight}))]`
- Палитра: аналогично для `color` и `background-color` — количество уникальных цветов.

## Smoke
- [ ] `vis.layout-broken` — явные поломки вёрстки на ключевых страницах (наложения, обрезанный текст, вылезающие блоки) → скриншот full page → дефект: видимая поломка.
- [ ] `vis.contrast` — контраст текста (`a11y.js`, правило `color-contrast`) → дефект: меньше 4.5:1 для обычного текста, меньше 3:1 для крупного.
- [ ] `vis.touch-targets` — на мобильной ширине тач-зоны ≥ 44×44 px (снимок выше) → дефект: основные кнопки и ссылки меньше 44 px без достаточных отступов (минимум WCAG 2.2 — 24×24, см. accessibility).
- [ ] `vis.images` — битые и растянутые изображения → `browser_evaluate` (`img.naturalWidth === 0`, соотношение сторон) → дефект: битые, искажённые, размытые.

## Standard (в дополнение к smoke)
- [ ] `vis.palette` — число и согласованность цветов → дефект: близкие, но разные оттенки для одной роли (несколько «почти одинаковых» синих у ссылок и кнопок).
- [ ] `vis.typography` — шрифты, размеры, межстрочный интервал, длина строки → дефект: больше 2–3 семейств, хаотичная шкала размеров, строки длиннее ~90 символов, основной текст мельче 16 px на мобильном.
- [ ] `vis.spacing` — отступы → дефект: несистемные отступы, разные отступы у одинаковых блоков, «прилипшие» элементы.
- [ ] `vis.grid-alignment` — выравнивание по сетке → дефект: элементы «гуляют» на несколько пикселей, разная ширина колонок у однотипных блоков.
- [ ] `vis.component-consistency` — кнопки, поля, карточки, бейджи выглядят одинаково на разных страницах → дефект: несколько стилей кнопок одной роли.
- [ ] `vis.states-hover` — hover на ссылках, кнопках, карточках (`browser_hover` + скриншот) → дефект: нет реакции на интерактивном элементе, реакция на неинтерактивном.
- [ ] `vis.states-focus` — видимый фокус (Tab + скриншот) → дефект: фокус не виден или почти не виден.
- [ ] `vis.states-active-disabled` — состояния нажатия и disabled → дефект: disabled выглядит как активный, нет пояснения причины.
- [ ] `vis.icons` — иконки одного набора, размера и толщины, выравнивание с текстом → дефект: смешение наборов, разные размеры, «прыгающая» базовая линия.
- [ ] `vis.loading-states` — скелетоны и спиннеры → дефект: прыжки макета при загрузке (связано с CLS).

## Deep (в дополнение к standard)
- [ ] `vis.theme-dark` — `browser_emulate_media` colorScheme=dark (и переключатель темы на сайте, если есть) → дефект: нечитаемые элементы, светлые «пятна», логотип теряется.
- [ ] `vis.theme-forced-colors` — forcedColors=active (режим высокой контрастности) → дефект: пропали границы и иконки.
- [ ] `vis.reduced-motion` — reducedMotion=reduce → дефект: анимации не отключаются (связано с accessibility).
- [ ] `vis.long-content` — длинные заголовки и имена, большие числа → дефект: переполнение, обрезка без многоточия.
- [ ] `vis.favicon-meta` — favicon, иконки приложения, theme-color.
- [ ] `vis.print` — печатная версия (media=print).
- [ ] `vis.redesign-notes` — по `ui-audit-redesign`: признаки «шаблонного» дизайна, слабая иерархия → передать в `product` как предложения редизайна.

## Типовые находки и severity
| Пример | Severity |
|---|---|
| Наложение блоков скрывает основной контент | High |
| Контраст основного текста ниже 4.5:1 | Medium (High, если текст нечитаем) |
| Тач-зоны основной навигации меньше 44 px | Medium |
| Нет видимого фокуса | Medium (дублируется в accessibility — слить) |
| Три разных стиля основной кнопки | Low |
| Несистемные отступы | Low |

## Что записывать в находку
- Скриншот с выделенной областью (обрезанный по элементу: `browser_take_screenshot` с `ref`) и при необходимости эталон для сравнения (как выглядит «правильный» экземпляр компонента).
- Вычисленные значения: цвета (hex), коэффициент контраста, размеры в px, шрифт, отступы.
- Ширину, браузер, тему.
- Предложение: конкретное значение (цвет, размер, отступ) или ссылку на соседний корректный компонент.
