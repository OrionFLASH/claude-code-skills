# content-i18n — тексты и локализация

Направление: `content-i18n` · Инструменты: Playwright MCP (`browser_snapshot`, `browser_evaluate` по видимому тексту), переключатель языка сайта (если не запрещён), скриншоты · Усилители: нет; при наличии — скилы проверки текста как справочник

## Цель
Найти ошибки текста и локализации, которые видит пользователь: смешение языков, неверные форматы чисел и дат, разнобой терминов, неверные дефис и тире, неправильные падежи и согласование, непереведённые строки. Если сайт не на английском, это часто самая большая группа дефектов.

Граница с `seo-content`: там мета-теги, заголовки страниц и индексация. Здесь все видимые тексты интерфейса: кнопки, подписи, подсказки, таблицы, уведомления, письма на экране.

## Безопасность в этом направлении
- Только чтение. Переключать язык или регион можно, только если это не запрещено (`url_guard action`). Частый пользовательский запрет — «не менять язык/регион/валюту».
- Тексты, которые появляются после действия (тосты, ошибки форм), вызывать только безопасными действиями, без отправки форм людям.
- Цитаты из личных данных (имена, ники, e-mail в интерфейсе) маскировать (`safety-rules.md` §5).

## Как собирать текст
- Видимый текст страницы с учётом iframe: `browser_snapshot` по каждому кадру (при `frames: all`) или
  `() => [...document.querySelectorAll('body *')].filter(e => e.offsetParent && e.childElementCount === 0 && e.innerText.trim()).map(e => e.innerText.trim()).slice(0, 2000)`.
- Подсказки и скрытый текст: `title`, `aria-label`, `placeholder`, `alt` — тоже интерфейс.
- Для каждого языка сайта из списка: пройти одни и те же ключевые экраны.

## Smoke
- [ ] `i18n.mixed-language` — смешение языков: английские слова и служебные строки в русском интерфейсе (`other`, `Lv.`, `Body`, `regulation.bin`, `undefined`, ключи вида `menu.title`) → находка на каждый тип строки с примерами мест.
- [ ] `i18n.untranslated` — непереведённые строки при выбранном языке: подсказки, тосты, пустые состояния, кнопки диалогов.
- [ ] `i18n.number-format` — числа по правилам языка: в русском разделитель тысяч — неразрывный пробел (`3 354`, не `3,354`), дробная часть — запятая (`1,84`, не `1.84`), проценты через пробел (`3,2 %`). Один формат на всём сайте (не `10,5` рядом с `6.5`).
- [ ] `i18n.date-format` — даты и время по языку (`8 октября 2026`, `08.10.2026`, 24-часовой формат), без `10/8/2026` и `AM/PM` в русском интерфейсе; относительное время («5 минут назад») склоняется правильно.
- [ ] `i18n.key-terms` — ключевые термины одинаковы на всех экранах: один объект называется одним словом («сохранение», а не то «сейв», то «сохранение»; «уровень», а не «Lv.»/«ур.»/«level»).

## Standard (в дополнение к smoke)
- [ ] `i18n.plural` — склонение с числами: «1 предмет, 2 предмета, 5 предметов», «21 час»; нет «1 предметов», «5 предмет(ов)».
- [ ] `i18n.case-agreement` — падежи и согласование в составных подписях: «Найдено 3 из 12», «из 860 000» не читается как «из» в другом смысле; шаблонные строки с подстановкой имени не ломают падеж.
- [ ] `i18n.dash-hyphen` — тире `—` между частями предложения и в диапазонах `1–3` (короткое), дефис только внутри слов; кавычки «ёлочки» в русском тексте; `ё` по правилам сайта, но единообразно.
- [ ] `i18n.units` — единицы и знаки: `×1,81`, `с`, `%`, валюта с пробелом и в нужном порядке; неразрывный пробел между числом и единицей.
- [ ] `i18n.truncation` — длинные переводы не обрезаются и не ломают вёрстку (немецкий, русский длиннее английского): кнопки, вкладки, таблицы.
- [ ] `i18n.lang-attr` — `lang` у `<html>` и у вставок на другом языке совпадает с текстом (связано с `seo.lang` и a11y — сливать).
- [ ] `i18n.typos` — опечатки и грамматика в интерфейсе (меню, подписи, подсказки).

## Deep (в дополнение к standard)
- [ ] `i18n.all-languages` — все языки из переключателя: экран открывается, нет пустых строк и ключей, числа и даты по правилам каждого языка.
- [ ] `i18n.rtl` — для RTL-языков (если есть): направление текста, зеркальные иконки.
- [ ] `i18n.glossary` — словарь терминов сайта: таблица «термин → где встречается → варианты», чтобы владелец выбрал один.

## Типовые находки и severity
| Пример | Severity |
|---|---|
| Экран на выбранном языке не открывается или показывает ключи вместо текста | High |
| Служебные английские слова или ключи в основном сценарии | Medium |
| Числа в английском формате или вперемешку в таблицах с данными (`3,354` и `3 354`) | Medium (Low, если одно место) |
| Разные названия одного объекта на разных экранах | Low (Medium, если путает в сценарии) |
| Неверное склонение, дефис вместо тире, опечатка | Low |

## Что записывать в находку
- Направление `content-i18n`, `type: content`, `check_id` из списка выше.
- Точная цитата, как на экране, и предлагаемая правка; язык интерфейса (`environment` и `account_state`, если текст зависит от входа).
- Все места, где встречается, списком (URL + блок или селектор), а не одна находка на каждое место.
- Для терминов: таблица вариантов и предложение, какой оставить.
- Скриншот с обводкой строки (`references/screenshots.md`).
