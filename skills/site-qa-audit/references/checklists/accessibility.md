# accessibility — Доступность

Направление: `accessibility` · Инструменты: `node/a11y.js` (axe-core, WCAG 2.2 AA), Playwright MCP (клавиатура: `browser_press_key`, `browser_snapshot` — дерево доступности) · Усилители: opentest `a11y-test` (не установлен — заменён `a11y.js`), browser-devtools `accessibility-auditor` (если включён), `ux-audit` (раздел axe)

## Цель
Проверить соответствие WCAG 2.2 уровня AA: автоматически (axe) и вручную (клавиатура, фокус, структура, альтернативные тексты, ARIA, язык).

## Безопасность в этом направлении
- Навигация с клавиатуры может «нажать» опасную кнопку клавишей Enter или Space. Перед каждым Enter/Space на элементе — проверка `url_guard action` по его тексту. Tab и Shift+Tab безопасны.
- `a11y.js` только загружает страницы и анализирует их, без кликов. Запускать с `--rules rules.json`.

## Smoke
- [ ] `a11y.axe.*` — `node/a11y.js <ключевые URL> --rules rules.json --out raw/a11y.json` (Chromium, desktop) → каждое нарушение axe = находка с `check_id` = `a11y.axe.<rule-id>` (например, `a11y.axe.color-contrast`, `a11y.axe.image-alt`, `a11y.axe.label`) → Critical/Serious axe — обязательно; Moderate/Minor — Low.
- [ ] `a11y.page-lang` — у `<html>` есть корректный `lang` → дефект: нет или не соответствует языку контента.
- [ ] `a11y.keyboard-basic` — Tab по главной странице: все интерактивные элементы достижимы, порядок логичен → дефект: элемент недостижим, порядок прыгает.
- [ ] `a11y.focus-visible` — фокус виден на каждом элементе → дефект: не виден (скриншот).

## Standard (в дополнение к smoke)
- [ ] `a11y.axe.*` — `a11y.js` на всех страницах до лимита и на мобильной ширине.
- [ ] `a11y.keyboard-trap` — нет ловушек фокуса (модальные окна, карты, встраивания, виджеты) → дефект: из элемента нельзя выйти Tab/Esc.
- [ ] `a11y.modal-focus` — модальное окно: фокус переходит внутрь, удерживается, после закрытия возвращается на вызвавший элемент.
- [ ] `a11y.skip-link` — ссылка «Перейти к содержимому» в начале Tab-порядка (на страницах с длинной навигацией).
- [ ] `a11y.headings` — иерархия заголовков (`browser_evaluate`: список h1–h6) → дефект: нет h1, несколько h1 без причины, пропуски уровней.
- [ ] `a11y.landmarks` — main, nav, header, footer → дефект: нет main, контент вне регионов (axe `region`).
- [ ] `a11y.alt-text` — осмысленность alt (не только наличие): декоративные — `alt=""`, информативные — описание → дефект: «image», имя файла, alt у декоративной картинки.
- [ ] `a11y.form-labels` — у полей видимые подписи, связанные с полем; ошибки связаны (`aria-describedby`) и озвучиваются.
- [ ] `a11y.aria` — ARIA по назначению: роли, состояния (`aria-expanded`, `aria-selected`), без лишних ролей на нативных элементах → проверка через `browser_snapshot` (accessible name и роль).
- [ ] `a11y.link-purpose` — понятные тексты ссылок («подробнее» × 10 без контекста — дефект).
- [ ] `a11y.target-size` — WCAG 2.5.8: цели не меньше 24×24 px или с достаточным отступом. Сводка одной строкой — `node <SKILL_DIR>/scripts/node/targets.js <URL> [--device pixel7]` («N из M < 24×24 по типам, K < 44×44»; ссылки внутри текста — отдельно, исключение 2.5.8). На телефоне — только при `media.touchValid: true` (`responsive-cross-browser.md` → `rsp.touch-emulation`), иначе результат недействителен.

## Deep (в дополнение к standard)
- [ ] `a11y.zoom-200` — увеличение 200% и reflow на 320 CSS px (1.4.10) → дефект: горизонтальный скролл, потеря контента.
- [ ] `a11y.text-spacing` — 1.4.12: применить межстрочный 1.5, межбуквенный 0.12em, межсловный 0.16em через `browser_evaluate` → дефект: текст обрезается.
- [ ] `a11y.reduced-motion` — `prefers-reduced-motion: reduce` (`browser_emulate_media`) → дефект: автоанимации, параллакс, автопрокрутка каруселей не отключаются; нет паузы у движущегося контента (2.2.2).
- [ ] `a11y.contrast-non-text` — 1.4.11: контраст границ полей, иконок, фокуса ≥ 3:1.
- [ ] `a11y.focus-not-obscured` — 2.4.11: фокус не перекрыт фиксированными шапками и баннерами.
- [ ] `a11y.dragging` — 2.5.7: перетаскивание (слайдеры, карты, сортировка) имеет альтернативу кликом или клавиатурой.
- [ ] `a11y.consistent-help` — 3.2.6: помощь и контакты на одном месте на всех страницах.
- [ ] `a11y.accessible-auth` — 3.3.8: вход без когнитивных тестов, разрешена вставка пароля (только наблюдение, без входа боевым аккаунтом).
- [ ] `a11y.redundant-entry` — 3.3.7: повторно вводимые в процессе данные подставляются.
- [ ] `a11y.media` — субтитры у видео, транскрипт у аудио, нет автоплея со звуком.
- [ ] `a11y.axe-cross-browser` — `a11y.js --browser webkit` (и firefox, если запускается).
- [ ] `a11y.screen-reader-names` — по `browser_snapshot`: у всех кнопок-иконок есть accessible name.

## Типовые находки и severity
| Пример | Severity |
|---|---|
| Ключевая функция недоступна с клавиатуры / ловушка фокуса | High |
| axe Critical (например, `button-name` на главном действии) | High |
| axe Serious (`color-contrast`, `label`, `image-alt` на информативных изображениях) | Medium |
| Нет видимого фокуса | Medium |
| Неправильная иерархия заголовков | Low |
| axe Moderate/Minor (`region`, `landmark-one-main`) | Low |

## Что записывать в находку
- axe: `rule-id`, impact, критерий WCAG (из tags), `helpUrl`, селекторы узлов (до 10) и их количество, фрагмент HTML.
- Клавиатура: последовательность нажатий, где теряется фокус, скриншот с фокусом.
- Критерий WCAG 2.2 (номер и уровень) — обязательно.
- Ширину, браузер; для axe — `raw/a11y*.json` как источник.
