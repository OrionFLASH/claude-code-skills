# device-config-compat — Конфигурации устройств

Направление: `device-config-compat` · Инструменты: `<SKILL_DIR>/scripts/matrix.py variants` (вариации и команды сброса), `adb_helpers.py` (ниже без пути и общих опций `--serial S --run-dir <RUN_DIR>`; PKG — `app.package` из run-config): `font-scale`, `density`, `rotate`, `dark-mode`, `locale`, `network`, `battery`, `doze`; `avd_manager.py start` (профили железа) · Усилители: Maestro или Appium — прогон одного сценария на всех ячейках, если установлены

## Цель
Проверить, что приложение работает и выглядит корректно на разных размерах экрана и плотностях, с крупным шрифтом, в обеих ориентациях, в тёмной теме, на другом языке и RTL, на слабом железе, при нехватке места, низком заряде и плохой сети. Каждая проверка выполняется в ячейке матрицы с нужной вариацией.

## Безопасность в этом направлении
- Перед каждым нажатием `adb_helpers.py tap …` guard.py проверяет действие сам: код 3 — запрет, записать «не проверено: запрет <rule>»; код 2 — спросить пользователя и повторить с `--confirmed` только после «да».
- Изменение настроек реального устройства (шрифт, плотность, поворот, тема, сеть, батарея) — только если в `stands.consent` для него разрешено (`scope: full`); иначе ячейку пропустить и записать «не проверено: нет согласия».
- Скорость сети (`network 3g|edge|gprs`) — только на своём эмуляторе.
- После каждой вариации выполнить её команды сброса из `matrix.py variants` (`font-scale 1.0`, `density reset`, `rotate portrait`, `dark-mode off`, `network online`, `battery reset`), чтобы не испортить следующую ячейку.
- Покупки, вход через внешние аккаунты, звонки, SMS, отправка сообщений реальным людям — никогда, в любой вариации.

## Smoke
- [ ] `cfg.font-1.3` — `font-scale 1.3`, `stop`, `launch` → ключевые экраны, `dump-ui` (кандидаты `visual.*`), `screenshot` → дефект: обрезанный текст, налезание, кнопки за краем, текст не масштабируется вовсе.
- [ ] `cfg.landscape` — `rotate landscape` на ключевых экранах → дефект: вёрстка сломана, контент недоступен, поля ввода закрыты клавиатурой без прокрутки.
- [ ] `cfg.dark` — `dark-mode on` (API 29+), `stop`, `launch` → дефект: нечитаемый текст, белые блоки, тема не применилась.
- [ ] `cfg.display-large` — вариация `display-large` (`density` +20%) → дефект: элементы не помещаются, обрезка, горизонтальный скролл там, где его нет на базе.
- [ ] `cfg.net-slow` — вариация `net-3g` (свой эмулятор) → основной сценарий → дефект: таймауты без сообщения, зависание.

## Standard (в дополнение к smoke)
- [ ] `cfg.font-2.0` — `font-scale 2.0` (нелинейное масштабирование на Android 14+) → дефект: потеря текста, наложения, недоступные кнопки (связано с `a11y.font-2.0`).
- [ ] `cfg.dark-font` — вариация `dark-font` (тёмная тема + шрифт 1.3) → дефект: проблемы, которых нет по отдельности.
- [ ] `cfg.screen-small` — профиль small (720×1280) → дефект: кнопки и диалоги не помещаются, важное только за прокруткой без индикации.
- [ ] `cfg.screen-tablet` — профиль tablet в обеих ориентациях → дефект: растянутый интерфейс, принудительная портретная ориентация, обрезка (на Android 16+ при targetSdk 36 запрет поворота на больших экранах игнорируется системой — проверить обе ориентации).
- [ ] `cfg.fold` — профиль fold (API 32+): сложить и разложить кнопками панели эмулятора вручную (команды в скилле нет) на ключевых экранах → дефект: потеря состояния, вёрстка не перестраивается, падение.
- [ ] `cfg.low-end` — профиль low-end (2 ГБ, 2 ядра): запуск, прокрутка, основной сценарий; `start-time --mode cold`, `gfxinfo` → дефект: падение по памяти, ANR, заметно хуже базовой ячейки.
- [ ] `cfg.rtl` — вариация `rtl` (`locale ar PKG`, API 33+; на старых API — `avd_manager.py start <AVD> --locale ar`) → дефект: вёрстка не зеркалится, стрелки «назад» смотрят не туда, текст наезжает.
- [ ] `cfg.locale` — вариация `locale` (язык из `devices.locale`) → дефект: язык не сменился полностью, обрезка длинных переводов.
- [ ] `cfg.offline-edge` — вариации `offline` и `net-edge` → дефект: пустые экраны без сообщений, бесконечные индикаторы.
- [ ] `cfg.battery` — вариации `battery-low` и `saver` → дефект: падение, остановка критичных функций без сообщения, принудительная тёмная тема ломает вид.

## Deep (в дополнение к standard)
- [ ] `cfg.low-1gb` — профиль low-1gb (1 ГБ, 1 ядро, API ≤ 29) → дефект: падение при старте, OutOfMemoryError в `crashes`, ANR.
- [ ] `cfg.storage-low` — свой профиль с малым разделом данных (`devices.custom`, `data: 2G`), заполненный кэшем и файлами вручную → загрузка, сохранение, обновление → дефект: падение, потеря данных, нет сообщения о нехватке места.
- [ ] `cfg.net-switch` — вариация `net-switch` во время загрузки → дефект: зависание, повторная отправка, ошибка без повтора.
- [ ] `cfg.doze` — вариация `doze` с приложением в фоне → `doze exit`, возврат → дефект: падение, синхронизация не возобновилась.
- [ ] `cfg.timezone` — вариация `timezone` → дефект: неверные даты и время (подробно — logic-state).
- [ ] `cfg.combined` — сочетание худших условий в одной ячейке: low-end + `font-2.0` + `landscape` + `net-edge` → дефект: проблема, которой нет при отдельных вариациях.

## Типовые находки и severity
| Пример | Severity (см. `references/severity.md`) |
|---|---|
| Падение или ANR на слабом железе при старте | Critical / High |
| Основное действие недоступно при шрифте 1.3 или 2.0 | High |
| Потеря состояния при складывании или повороте планшета | High / Medium |
| Вёрстка не зеркалится в RTL | Medium |
| Нечитаемые элементы в тёмной теме | Medium |
| Растянутый телефонный интерфейс на планшете | Low |
| Мелкая обрезка текста при display-large | Low |

## Что записывать в находку
- Экран — activity из `current`; элемент — `id=<resource-id>` или `text="…"` + класс.
- Окружение: API, профиль железа (RAM, ядра, `WxH@dpi`), вариация с командами, ячейка матрицы `c01…`; в каких вариациях дефекта нет.
- Шаги с чистого запуска (`clear` → `launch --cold`) после применения вариации; repro_rate («3/3»).
- Скриншоты `screenshots/<id>-<вариация>.png` и эталон `screenshots/<id>-base.png` для сравнения.
- Для слабого железа — метрики (`start-time`, `gfxinfo`) и `logcat_excerpt` из `crashes` (замаскированный).
