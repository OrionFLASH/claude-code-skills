# content-i18n — Тексты и локализация

Направление: `content-i18n` · Инструменты: `<SKILL_DIR>/scripts/adb_helpers.py` (ниже без пути и общих опций `--serial S --run-dir <RUN_DIR>`; PKG — `app.package` из run-config): `dump-ui --json F` (все тексты экрана), `locale TAG PKG` (язык приложения, API 33+), `timezone`, `notifications`, `screenshot`; `avd_manager.py start <AVD> --locale …` (системный язык); `apk_info.py` (`locales`); `matrix.py variants` (rtl, locale) · Усилители: глоссарий из памяти приложения, проверка орфографии по выгрузке текстов

## Цель
Проверить тексты интерфейса: опечатки, смешение языков, непереведённые строки и ключи ресурсов, форматы дат, чисел и валют по локали, множественные формы, RTL, длинные переводы, тексты ошибок и уведомлений, единую терминологию.

## Безопасность в этом направлении
- Перед каждым нажатием `adb_helpers.py tap …` guard.py проверяет действие сам: код 3 — запрет, записать «не проверено: запрет <rule>»; код 2 — спросить пользователя и повторить с `--confirmed` только после «да». В другой локали guard проверяет и переведённые тексты кнопок — при сомнении проверить вручную `guard.py action --text "<текст>" --config <RUN_DIR>/run-config.yaml`.
- Кириллица и emoji через adb не вводятся (`text` — только ASCII): ввести вручную в окне эмулятора или через ADBKeyBoard с согласия пользователя.
- Смена системного языка — перезапуском своего эмулятора (`avd_manager.py start <AVD> --locale …`); на реальном устройстве — только с согласием из `stands.consent` (`scope: full`). После проверки вернуть язык (`locale <исходный> PKG`).
- Ссылки на правовые тексты и справку, ведущие в браузер, — не открывать: записать «ведёт в браузер — не проверялось».

## Smoke
- [ ] `i18n.typos` — тексты ключевых экранов из `dump-ui --json F` → проверка орфографии и грамматики → дефект: опечатки, ошибки согласования, «ё/е» непоследовательно.
- [ ] `i18n.mixed-language` — один экран на одном языке → дефект: английские строки в русском интерфейсе (кнопки, ошибки, заглушки) и наоборот.
- [ ] `i18n.untranslated-keys` — поиск в выгрузке текстов: ключи ресурсов (`title_main_screen`), `%s`, `%1$d`, `{name}`, `null`, `TODO`, `lorem ipsum` → дефект: служебная строка видна пользователю.
- [ ] `i18n.error-texts` — тексты ошибок (сеть через `network offline`, неверный ввод) → дефект: технический английский текст, код без объяснения, не на языке приложения.
- [ ] `i18n.terminology` — термины сверить с глоссарием из памяти приложения → дефект: одно понятие названо по-разному на разных экранах.

## Standard (в дополнение к smoke)
- [ ] `i18n.app-locale` — каждый язык из `apk-info.json` → `locales`: `locale TAG PKG` (API 33+; на старых API — `avd_manager.py start <AVD> --locale TAG`), `stop`, `launch` → дефект: язык сменился частично, остатки прежнего языка, падение.
- [ ] `i18n.long-translations` — `locale de-DE PKG` (длинные слова) → `dump-ui` (кандидаты `visual.text-ellipsized`, `visual.overlap`), `screenshot` → дефект: обрезанные кнопки и заголовки, перенос посреди слова, текст за краем.
- [ ] `i18n.rtl` — вариация `rtl` (`locale ar PKG`) → дефект: вёрстка не зеркалится, стрелки «назад» и «вперёд» не развёрнуты, числа, телефоны и латиница внутри арабского текста перепутаны.
- [ ] `i18n.formats` — даты, время, числа, валюты, единицы по локали (ru-RU: `08.10.2026`, `1 234,50 ₽`, 24-часовой формат; en-US: `10/8/2026`, `$1,234.50`, AM/PM) → дефект: жёстко зашитый формат, разделители не по локали.
- [ ] `i18n.plurals` — русские формы для 1, 2, 5, 11, 21, 22 (1 файл, 2 файла, 5 файлов, 11 файлов, 21 файл) → дефект: «5 файла», «1 файлов», «1 items».
- [ ] `i18n.notifications` — `notifications PKG` и `shade open` после смены языка → дефект: уведомления и названия каналов на прежнем или другом языке.
- [ ] `i18n.permission-rationale` — объяснения перед системным диалогом разрешения на языке приложения; сам системный диалог — на языке системы (это не дефект, если языки различаются) → дефект: объяснение не переведено.
- [ ] `i18n.non-latin-input` — ввести вручную (окно эмулятора или ADBKeyBoard с согласия) кириллицу, emoji, диакритику в поля поиска и форм → сохранить и открыть снова → дефект: «кракозябры», вопросительные знаки, обрезка emoji, поиск не находит кириллицу.
- [ ] `i18n.typography` — кавычки «», тире и дефис, многоточие, регистр заголовков и кнопок единообразны → дефект: смешение стилей на одном экране.
- [ ] `i18n.dynamic-content` — контент с сервера (новости, каталоги, сообщения системы) на языке приложения → дефект: интерфейс переведён, данные — нет без пометки.

## Deep (в дополнение к standard)
- [ ] `i18n.all-locales` — полный проход ключевых экранов на каждом языке из `locales` → таблица «экран × язык» с дефектами.
- [ ] `i18n.pseudo-locales` — если сборка содержит псевдолокали (обычно отладочная): `locale en-XA PKG` и `locale ar-XB PKG` → дефект: строки без акцентов (не вынесены в ресурсы), обрезка при удлинении.
- [ ] `i18n.timezone-dates` — `timezone Asia/Tokyo` + другой язык → дефект: относительные даты («вчера») и дни недели не на языке приложения или с неверным днём.
- [ ] `i18n.a11y-labels` — метки contentDescription в `dump-ui` на другом языке → дефект: метки остались на исходном языке.
- [ ] `i18n.sorting` — сортировка по алфавиту на русском и другом языке → дефект: «ё» в конце списка, регистр влияет на порядок, латиница и кириллица перемешаны.
- [ ] `i18n.legal-help` — правовые тексты и справка внутри приложения на языке интерфейса → дефект: доступны только на одном языке без пометки.

## Типовые находки и severity
| Пример | Severity (см. `references/severity.md`) |
|---|---|
| Ключ ресурса или `%s` вместо текста на основном экране | High / Medium |
| Обрезанная кнопка основного действия в одном из языков | Medium |
| Вёрстка не зеркалится в RTL при заявленной поддержке арабского | Medium |
| Неверная множественная форма, формат даты не по локали | Low |
| Опечатка в заголовке или кнопке основного экрана | Low / Medium |
| Смешение языков во второстепенном экране | Low |
| Непоследовательные кавычки и тире | Info |

## Что записывать в находку
- Экран — activity из `current`; элемент — `id=<resource-id>` или `text="…"` + класс; точный текст «как есть» и предлагаемое исправление.
- Язык приложения и системы, часовой пояс, вариация (`locale`, `rtl`), API, профиль железа, ячейка матрицы `c01…`.
- Шаги с чистого запуска (`clear` → `launch --cold` → смена языка); repro_rate («3/3»).
- Скриншот `screenshots/<id>-<язык>.png` и, для сравнения, тот же экран на основном языке.
- Для терминологии — ссылку на запись глоссария из памяти приложения.
