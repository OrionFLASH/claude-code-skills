# Журнал изменений android-qa-audit

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — SemVer, теги `android-qa-audit/vX.Y.Z`.

## [1.0.0] — 2026-10-08
Первая версия: QA-тестирование Android-приложений по APK / split APK / `.apks` / AAB или установленному пакету на эмуляторах и устройствах через adb. «Брат» `site-qa-audit` по структуре: подтверждение намерения, опрос, память о приложении, безопасность через guard, матрица и потоки, журнал, отчёт, черновики issues, gitignore, уборка. Статус — «в разработке»: на реальном эмуляторе и устройстве не прогонялся (проверено офлайн на фейковом adb и SDK и только чтением на машине с Android SDK).

### Добавлено
- Запуск по `/android-qa-audit` и по смыслу запроса (RU/EN-триггеры в `description`, когда не использовать); при автозапуске — вопрос «Похоже, вы хотите протестировать Android-приложение … Запустить?», при «Нет» ничего не создаётся.
- Опрос (`references/intake.md`): что за приложение и для чего, источники, вход, что тестируем и успех, версии Android (рекомендация из minSdk/targetSdk), конфигурации (ОЗУ, ядра, диск, экран, шрифт, тема, ориентация, язык и RTL, сеть, батарея, Doze, часовой пояс), виды тестов, 11 направлений, глубина, стенды и согласие на реальные устройства, запреты, потоки (1–4), GitHub issues, куда записать итоги. `scripts/intake.py from-text` — черновик run-config из свободного запроса.
- Разбор приложения `scripts/apk_info.py`: aapt2/aapt (badging + xmltree манифеста), apksigner; пакет, версии, SDK, разрешения (опасные, особые, с какого API запрашиваются), launcher, ABI и совместимость с эмулятором хоста, debuggable, allowBackup, cleartext, экспортируемые компоненты (с правилами по умолчанию), deep links, подпись, кандидаты пассивной безопасности; `.apks`/`.xapk`, AAB через bundletool (`build-apks`), установленное приложение (`installed --pull-to`); копия APK в папке прогона с `SHA256SUMS`.
- Стенды `scripts/avd_manager.py`: список AVD с владельцем (свои — `qa-*` + метка `android-qa-audit.json`), образы и их загрузка через sdkmanager (план с оценкой размера, `--yes` и лицензии — только с согласия), создание AVD с ОЗУ/ядрами/диском/экраном/density, запуск (свободный порт, headless, cold boot, снимки, скорость сети, язык, часовой пояс), ожидание загрузки, остановка только своих эмуляторов, удаление только своих AVD, уборка по `stands.json`; чужие AVD — только `--allow-foreign` с `-read-only`.
- Управление устройством `scripts/adb_helpers.py`: установка/обновление/удаление/очистка, запуск и время старта (cold/warm/hot), смерть процесса в фоне, trim-memory, deep links; дерево элементов uiautomator с кандидатами (`a11y.missing-label`, `a11y.touch-target` 48 dp, `visual.offscreen`, `visual.overlap`, `visual.text-ellipsized`), нажатия по тексту/id/описанию, свайпы, ввод (секреты из переменных окружения не печатаются), клавиши, скриншоты, видео; поворот, шрифт, масштаб экрана, тёмная тема, язык приложения, часовой пояс, сеть (режим полёта, Wi-Fi, скорость эмулятора), батарея, экономия, Doze, standby, анимации; разрешения, уведомления; logcat (фоновая запись с маскированием), падения и ANR (logcat + dropbox), meminfo, gfxinfo, batterystats, размер, monkey с seed.
- Безопасность `scripts/guard.py` (коды 0/2/3, как `url_guard` у сайта): базовые запреты (покупки, вход через внешние аккаунты, звонки и SMS — и в эмуляторе, отправка людям — спросить, удаление аккаунта, администратор устройства, чужие приложения), правила пользователя (`forbidden_packages`, `forbidden_screens`, `forbidden_deeplinks`, `forbidden_actions`, `require_confirmation_actions`, `preapproved_actions`, `adb_require_confirmation`), классификация adb-команд (чтение / приложение / устройство / запрет) × стенд (свой эмулятор / чужой эмулятор / реальное устройство) × согласие (`read-only`, `app-only`, `full`); журнал `logs/blocked.jsonl`; `selftest` (63 случая). `scripts/masking.py` — маскирование.
- Матрица `scripts/matrix.py`: API × железо × вариации по глубине (smoke / standard / deep, `references/depth-matrix.md`), `matrix.mode: full`, реальные устройства и чужие AVD отдельными ячейками, распределение по потокам (до 4, по ОЗУ хоста и рекомендации `check_env`).
- Окружение `scripts/check_env.py` (+ `.sh`, `.ps1`): Java, SDK (в т.ч. найден, но не в PATH — строки для zsh и PowerShell), adb, emulator, cmdline-tools, build-tools, образы и ABI, AVD, устройства (unauthorized/offline), ускорение (HVF/WHPX/KVM), ОЗУ, ядра, диск, рекомендация потоков, bundletool, scrcpy, Maestro, Appium, gh, `ANDROID_QA_OUTPUT_DIR`, усилители и запрещённые плагины.
- Находки и отчёт: `templates/finding.schema.json` (Android-поля: экран, окружение с API, профилем, ОЗУ, ABI, стендом, ячейкой; `repro_rate`, `crash`, `logcat_excerpt`, `recordings`), `validate_findings.py`, `fingerprint.py` (отпечаток по направлению, пункту, пакету, экрану, элементу; сверка с выгрузкой `gh issue list`), `render_draft.py` (черновики issues и `index.md` с командами `gh`, ничего не публикует; disclosure, marker, severity_map, вложения), `build_report.py` (report, summary, publish-table: матрица, падения, метрики, кандидаты APK, запреты).
- Память о приложении `<OUTPUT_ROOT>/qa-runs/.app-context/<package>/context.md` + `sources.json` (`templates/app-context.md`): «как есть / обновить / изучить заново», без секретов и персональных данных.
- Общие модули репозитория `shared/scripts/runjournal.py` (журнал прогона, тот же, что `site-qa-audit/scripts/journal.py`) и `shared/scripts/qa_gitignore.py` (несколько шаблонов, режимы gitignore/exclude/keep); обёртки `scripts/journal.py`, `scripts/gitignore_helper.py` (по умолчанию `qa-runs/`, `*.apk`, `*.aab`, `*.apks`, `*.keystore`).
- Справочники: setup, intake, safety-rules, stands, device-control, depth-matrix, parallelism, plugins-map, severity, repo-sync, run-files, checklists (11 направлений: functional, logic-state, ux, visual-ui, device-config-compat, lifecycle-resilience, accessibility, performance, security-passive, compatibility, content-i18n).
- `INSTALL.md` — установка и обновление для macOS, Windows и Linux: JDK, Android SDK (Android Studio или command-line tools, brew/winget), переменные окружения, лицензии, ускорение, образы, AVD, необязательные программы, скил (маркетплейс, клон + `tools/install.*`, копия), частые проблемы и коды `INSTALL_FAILED_*`, промпты для Claude Code.

### Тесты
- `tests/unit.sh`: офлайн, фейковые adb и SDK (`tests/helpers/fake_adb.py`, `fake_tools.py`), изолированные HOME и AVD; синтаксис Python 3.9; guard, apk_info (aapt2 и aapt), avd_manager (создание, запуск, остановка, отказ для чужих AVD, уборка), adb_helpers (запреты нажатий и adb, реальные устройства и согласие, разбор метрик, падений, monkey), matrix, intake, validate/fingerprint/render_draft/build_report, gitignore_helper, маскирование, универсальность.
