# product-strategy

Стратегия развития и роста продукта по текущему репозиторию: опрос владельца, проверка и установка инструментов, анализ кода и приложения, рынок и конкуренты, реестр 50–150 предложений с оценками (RICE, ICE, WSJF, Кано, TypeSafe), план на месяцы и годы, макеты и референсы дизайна, интерактивная веб-страница, XLSX, PPTX, PDF
