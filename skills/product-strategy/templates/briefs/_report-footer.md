# Хвост «Формата отчёта»: расхождения с фактами, предпосылки, отступления от брифа (общий для брифов)

Подключается строкой в конце раздела «Формат отчёта» брифа. Отчёт агента оркестратор сохраняет как
`<OUT>/build/agent-reports/<бриф>[-<группа>].md`; блоки ниже разбирает `scripts/collect_reports.py`: расхождения →
`data/fact-check.candidates.json` (оркестратор подтверждает кандидатов, а не переписывает их из отчётов), предпосылки →
`--deps`, отступления → `--retro`.

В конце отчёта — отдельные блоки в таком порядке: «Расхождения с фактами» (все агенты), строки `ПРЕДПОСЫЛКА:` (авторы
разделов, спецификаций, экспериментов, макетов, схем — если есть), «Отступления от брифа» (все агенты).

## Расхождения с фактами

Блок с заголовком и одной строкой на расхождение, ровно 4 поля через « — » (длинное тире с пробелами вокруг):

```
## Расхождения с фактами
- <факт> — <как во входах> — <как нашёл> — <источник: путь:строка или URL>
```

Расхождений нет — под заголовком одна строка `нет`.

Правила:
- поле «факт» — короткое имя одного факта (цена тарифа, длина пробного периода, число тестов, есть ли функция X), одинаковое
  у всех агентов для одного факта;
- «как во входах» — значение из входа (факт-лист, `product-understanding.md`, досье) с файлом, «как нашёл» — твоё значение;
- внутри полей не использовать « — » (заменить на «-» или запятую); источник — `путь:строка` или URL, без пересказа;
- вместо строк можно дать JSON-блок (тот же смысл, поля обязательны):

```json
{"discrepancies": [{"fact": "пробный период", "input_value": "7 дней (strategy-facts.md)", "found_value": "3 дня", "source": "https://…/pricing"}]}
```

## Предпосылки, которых нет в реестре (авторы разделов, спецификаций, экспериментов, макетов, схем)

Если пишешь, что одно предложение нельзя сделать без другого, а в `dependencies` реестра этой связи нет, — отдельной строкой
(её собирает `collect_reports.py --deps` в `build/deps-patch.json`):

```
ПРЕДПОСЫЛКА: P038 ← P033, P111 | почему без них не работает
```

Слева — одно предложение, справа — его предпосылки (только P-id из реестра); после « | » — одна фраза. Нет таких — строк не
писать. Предпосылки, которых нет в реестре вовсе (нужно новое предложение), — обычной строкой отчёта «нужно: …», не `ПРЕДПОСЫЛКА:`.

## Отступления от брифа

Отдельный блок отчёта: что сделано не так, как велит бриф (другой путь выдачи, пропущенный шаг, временный скрипт, чтение
не перечисленного входа), и почему. Нет — одна строка `нет`. Блок собирает `collect_reports.py --retro` в `build/retro.md`.

```
## Отступления от брифа
- <что> — <почему>
```
