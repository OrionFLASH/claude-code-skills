## С чего начать
1. **`deliverables/index.html`** — главная веб-страница: резюме, стратегия, реестр с фильтрами и сортировкой, оценки, графики, план (Гант), Kanban, макеты, референсы дизайна, конкуренты, источники. Открывается офлайн в браузере.
2. **`deliverables/REPORT.md`** — что сделано, три главные ставки, что не удалось, вопросы владельцу, решения на проверку.
3. **`deliverables/strategy.pptx`** / **`strategy.pdf`** — презентация (топ-предложения карточками, приложения таблицами).
4. **`deliverables/strategy.xlsx`** — реестр, оценки с редактируемыми весами, модель экономики, источники, KPI, Kanban.
5. **`research/strategy.md`** — полный текст стратегии (разделы 1–17).
6. **`design-refs/`** — карточки макетов для постановки задач на интерфейс (`design-refs/README.md`).

## Как пересобрать
Все результаты собираются из `data/` и `research/` — правьте исходники, а не готовые файлы.

Все пути в этой папке — относительные; команды запускаются из корня репозитория (или из любого места с `OUT=<путь к папке прогона>`).

```bash
S=<SKILL_DIR>/scripts          # путь печатает: python3 <SKILL_DIR>/scripts/skill_dir.py
OUT=<путь к этой папке>        # например strategy/<дата> от корня репозитория
export PS_NODE_DIR=~/.cache/product-strategy/node   # Node-модули (ставит check_env.py --install-node)

python3 $S/check_registry.py $OUT       # реестр: поля, минимумы, доказательства
python3 $S/score.py $OUT                # оценки, приоритеты, зависимости, чувствительность
python3 $S/validate_scores.py $OUT      # независимый пересчёт
python3 $S/model.py $OUT                # юнит-экономика (если включена)
python3 $S/charts.py $OUT               # графики (допустимые ключи: --list-keys)
node    $S/node/shoot_mockups.mjs $OUT       # PNG макетов + индекс (автообнаружение)
python3 $S/link_mockups.py $OUT         # связь макетов с предложениями
python3 $S/merge_sources.py $OUT --keep-ids   # источники
python3 $S/assemble_strategy.py $OUT --insert-mockups   # research/strategy.md из build/parts/
python3 $S/build_all.py $OUT            # HTML, XLSX, колода, PPTX, PDF (включённые форматы)
python3 $S/build_html.py $OUT --lite    # лёгкая страница (картинки — в deliverables/assets/)
python3 $S/check_links.py $OUT          # ссылки
node    $S/node/smoke_html.mjs $OUT          # автотест веб-страницы
```

Изменили веса — правьте `data/weights.json` (или строку весов в листе «Оценки» XLSX — там пересчёт формулами), затем `score.py` → `charts.py` → `assemble_strategy.py` (обновит ранги в тексте) → `build_all.py`.
Правите текст стратегии — правьте части `build/parts/strategy-*.md`, а не `research/strategy.md`: сборщик пересобирает его из частей и подставляет актуальные ранги.
Перенесли папку — `python3 $S/relocate_run.py <старая> <новая> --repo <корень репозитория>`.

## Обозначения
- `P001…` — предложения реестра; на веб-странице кликабельны. Ранги в тексте подставлены сборщиком на дату сборки.
- Шаги, отмеченные в отчёте «выключено выбором», не выполнялись по решению владельца — это не ошибка.
- `[факт: источник, дата]`, `[оценка: метод]`, `[допущение]` — достоверность цифр.
- «Концепт, не существующая функция» — макет; «Текущее состояние, <дата>» — реальный скриншот.
