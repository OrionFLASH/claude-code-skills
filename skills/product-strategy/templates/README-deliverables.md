## С чего начать
1. **`deliverables/index.html`** — главная веб-страница: резюме, стратегия, реестр с фильтрами и сортировкой, оценки, графики, план (Гант), Kanban, макеты, референсы дизайна, конкуренты, источники. Открывается офлайн в браузере.
2. **`deliverables/REPORT.md`** — что сделано, три главные ставки, что не удалось, вопросы владельцу, решения на проверку.
3. **`deliverables/strategy.pptx`** / **`strategy.pdf`** — презентация (топ-предложения карточками, приложения таблицами).
4. **`deliverables/strategy.xlsx`** — реестр, оценки с редактируемыми весами, модель экономики, источники, KPI, Kanban.
5. **`research/strategy.md`** — полный текст стратегии (разделы 1–17).
6. **`design-refs/`** — карточки макетов для постановки задач на интерфейс (`design-refs/README.md`).

## Как пересобрать
Все результаты собираются из `data/` и `research/` — правьте исходники, а не готовые файлы.

```bash
S=<SKILL_DIR>/scripts          # путь печатает: python3 <SKILL_DIR>/scripts/skill_dir.py
OUT=<путь к этой папке>

python3 $S/check_registry.py $OUT       # реестр: поля, минимумы, доказательства
python3 $S/score.py $OUT                # оценки, приоритеты, чувствительность
python3 $S/validate_scores.py $OUT      # независимый пересчёт
python3 $S/model.py $OUT                # юнит-экономика (если включена)
python3 $S/charts.py $OUT               # графики
node    $S/node/shoot_mockups.mjs $OUT       # PNG макетов + индекс
python3 $S/build_all.py $OUT            # HTML, XLSX, колода, PPTX, PDF
python3 $S/check_links.py $OUT          # ссылки
node    $S/node/smoke_html.mjs $OUT          # автотест веб-страницы
```

Изменили веса — правьте `data/weights.json` (или строку весов в листе «Оценки» XLSX — там пересчёт формулами), затем `score.py` → `charts.py` → `build_all.py`.
