## Словарь
Источник для `build_appendix.py`. Формат строки: `- **Термин** [синонимы: a; b] — определение`. Синонимы ищутся в тексте так же, как термин (латиница — без учёта регистра).

- **RICE** — оценка приоритета: охват × влияние × уверенность / трудозатраты; сравнивает предложения разного масштаба.
- **ICE** — влияние × уверенность × простота; быстрая оценка без данных об охвате.
- **WSJF** [синонимы: Weighted Shortest Job First] — стоимость задержки / длительность; что выгоднее делать раньше.
- **Кано** [синонимы: модель Кано; Kano] — деление функций на обязательные, линейные и восхищающие по реакции пользователей.
- **Composite** [синонимы: композитный балл; composite] — сводный балл предложения из нормированных RICE, ICE, WSJF и поправки на риск (веса — `data/weights.json`).
- **Ранг с учётом зависимостей** [синонимы: dep_rank] — место предложения, если оно не может идти раньше своих предпосылок.
- **Критический путь** [синонимы: critical path] — цепочка предпосылок, от которой зависит срок главных ставок.
- **Класс доказательств** [синонимы: класс A; класс B; класс C; класс D] — сила подтверждения предложения: A — данные или первоисточник, B — сильный косвенный сигнал, C — слабый сигнал, D — рассуждение без источника.
- **[ДОПУЩЕНИЕ]** [синонимы: допущение] — значение, принятое без подтверждения; требует проверки владельцем.
- **North Star** [синонимы: Полярная звезда; метрика North Star] — одна главная метрика ценности продукта, к которой привязаны цели.
- **AARRR** [синонимы: пиратская воронка] — воронка «привлечение → активация → удержание → рекомендации → доход».
- **JTBD** [синонимы: Jobs To Be Done; работа, которую нанимают] — задача пользователя, ради которой он «нанимает» продукт.
- **CAC** — стоимость привлечения платящего клиента: маркетинговые расходы / число новых платящих.
- **LTV** — доход от клиента за время жизни: ARPU × маржа / отток.
- **ARPU** — средний доход на пользователя (или платящего) за период.
- **Отток** [синонимы: churn] — доля пользователей или платящих, ушедших за период.
- **Окупаемость** [синонимы: payback] — срок, за который доход от клиента покрывает CAC.
- **MDE** [синонимы: минимальный обнаруживаемый эффект] — наименьшее изменение метрики, которое эксперимент способен заметить при заданных α и мощности.
- **A/B-тест** [синонимы: A/B; эксперимент A/B] — сравнение вариантов на случайно разделённых группах пользователей.
- **OKR** — цели и ключевые результаты на квартал.
- **MVP** — минимальная версия продукта, проверяющая главную гипотезу.
- **ASO** — оптимизация карточки приложения в магазинах.
- **SEO** — оптимизация для поисковых систем.
- **GEO** [синонимы: Generative Engine Optimization] — оптимизация для ответов ИИ-поисковиков.
- **TypeSafe** [синонимы: Jev] — модель, оценивающая вероятность успеха предложения по его описанию (общие знания, без данных продукта).
- **Pre-mortem** [синонимы: премортем] — разбор «ставка провалилась — почему» до запуска.
- **Kanban** — доска задач с колонками и лимитами незавершённой работы (WIP).
- **Гант** [синонимы: диаграмма Ганта; gantt] — план работ по месяцам с зависимостями (`data/gantt.json` — единый источник дат).
- **P-id** — номер предложения реестра (`P001…`), по нему связаны текст, таблица и страница.
