# Типичные проблемы и решения

Установка инструментов — `references/tools.md`; проверка — `python3 <SKILL_DIR>/scripts/check_env.py --out <OUT>`.

## Среда и инструменты

| Проблема | Решение |
|---|---|
| Нет Node или версия < 18 | установить по `references/tools.md`; без Node недоступны скриншоты, макеты, PPTX, PDF → собрать HTML и XLSX, остальное отметить в REPORT как сокращённое |
| Нет Playwright или Chromium | `check_env.py --install-node <OUT>` (модули — в кэш `PS_NODE_DIR`, по умолчанию `~/.cache/product-strategy/node`); не ставить глобально и не класть в `<OUT>`. Нет сети для загрузки браузера — использовать системный Chrome через `channel: 'chrome'`, если скрипт это поддерживает (`--help`), иначе браузерный MCP для ручных скриншотов |
| Скрипт не находит `playwright`/`pptxgenjs` | задать `PS_NODE_DIR=<кэш Node-модулей>` (тот, куда ставил `check_env.py --install-node`; в старых прогонах — `<OUT>/build/node`); агентам — тот же путь в брифе; скрипты из scratchpad модули не резолвят |
| В результате прогона 26 МБ Node-модулей (`<OUT>/build/node`) | прогон 1.0: перенести в кэш — `check_env.py --install-node` ставит в `PS_NODE_DIR`, `<OUT>/build/node` удалить; `relocate_run.py` по умолчанию его не копирует (`--with-node` — копировать) |
| `timeout: command not found` (macOS) | в macOS нет `timeout`: `gtimeout` из coreutils (если установлен) или ограничение времени в Python — `subprocess.run(cmd, timeout=N)`; не строить проверки на `timeout` |
| Нет `gh` или не авторизован | Issues не читаются: пропустить `issues_export.py`, взять спрос из сообществ; уверенность «карты спроса» понижена; записать в REPORT. Владелец может выполнить `gh auth login` сам |
| Нет `TYPESAFE_API_KEY` | `typesafe_eval.py` пишет `skipped` и выходит без ошибки; колонка TypeSafe в результатах пустая с пометкой; модель субагентов — по правилу из `references/orchestration.md` |
| Нет скилла `typesafe-triage` | правило по умолчанию: сбор/механика — sonnet, синтез/дизайн/оценка — opus |
| `CERTIFICATE_VERIFY_FAILED` в Python | системные сертификаты не подхвачены: на macOS — `Install Certificates.command` от установщика Python; иначе `SSL_CERT_FILE` на файл CA-бандла системы |
| `python3 -I` ломает импорт библиотек | `-I` — только для скриптов, читающих недоверенные файлы; генераторы графиков запускать без `-I` |
| zsh: `no matches found` на `--include=*.html` | брать glob в кавычки: `--include='*.html'` |
| `grep -c` вернул 0 и оборвал цепочку `&&` | проверки с ненулевым кодом не ставить в середину цепочки; использовать `;` или `|| true` |
| Ключ мелькнул в выводе | никогда не грепать файлы настроек целиком; ключ отозвать/сменить (сказать владельцу), проверить, что его нет в `<OUT>` |
| Папка прогона «не там», где ждал владелец | место папки фиксируется в опросе; в начале фазы 0 показать путь к главному результату. Уже нужно перенести — `init_run.py <OUT> --relocate <NEW>` или `relocate_run.py <OUT> <NEW> --repo <repo> [--move] [--dry-run]`: абсолютные пути в текстовых файлах заменяются, `run-config.json → output.*` обновляется; затем `build_all.py <NEW>` |
| Корневой `.gitignore` молча исключил `<OUT>/build` (правило `build/`) | `check_gitignore.py <OUT> --repo <repo>` показывает игнорируемые файлы и правило; `--fix` пишет `!`-исключения во вложенный `<OUT>/.gitignore` (сильнее родительских правил), корневой файл не трогается; затем `git add -n <OUT>` |
| В файлах прогона абсолютные пути с именем пользователя | `grep -rnE '/(Users|home)/[^ ]+' <OUT> --include='*.md' --include='*.json' --include='*.html'`; переписать на относительные (`relocate_run.py` делает это при переносе); брифы заполнять с `{OUT}` от корня репозитория |
| Чек-лист прогона конфликтует с `TASKS.md` владельца | чек-лист скилла — `<OUT>/STRATEGY_TASKS.md`; корневой `TASKS.md` не трогать |

## Приложение и браузер

| Проблема | Решение |
|---|---|
| Приложение не запускается локально | 3–4 попытки (README, Makefile, Docker, `package.json`), затем публичный адрес; нет и его — по коду с пометкой «уверенность понижена»; причину — в STATUS и REPORT |
| Нужен вход в аккаунт | только тестовые учётки из фикстур проекта; иначе пройти путь до формы входа и описать остальное по коду |
| Публичное демо закрывает почти все экраны | реальные экраны — в песочнице (отдельный корень данных, сгенерированные данные, свой порт): `references/run-sandbox.md`; иначе по коду с пониженной уверенностью |
| SPA с хэш-маршрутами: все снимки называются `home`, файлы перезаписываются | `audit_site.mjs … --routes-from hash`: маршруты из `#/…`, слаг из полного URL; проверить, что у разных маршрутов разные PNG |
| Нужны раскрытые состояния (карточка, модалка, вкладка, смена роли) | `audit_site.mjs … --click-safe` — клики только по безопасному списку элементов (формат — `--help`); никаких «удалить», «оплатить», «отправить», входов и внешних ссылок; свои скрипты Playwright не писать |
| `tokens.css` бедный (несколько переменных), нет тёмной темы | `audit_site.mjs … --themes light,dark` — CSS custom properties из `:root` и тёмной темы; если продукт без переменных — токены из исходников CSS (`references/design.md`) |
| `measure_hotspots`: непонятно, на своих ли местах зоны | `measure_hotspots.mjs … --draw <png>` — рамки зон поверх макета, смотреть через Read |
| Параллельные агенты затирают `data/mockups-check.json` | агенты запускают `shoot_mockups.mjs <OUT> --only <ключ>` → свой `data/mockups-check.<ключ>.json`; агрегат строит оркестратор запуском без `--only`; `mockups-index.json` — автообнаружение, руками не править |
| `shoot_mockups` не видит новый макет | файл должен лежать в `mockups/concepts/<ключ>.html` с `data-viewport` у `<html>` для мобильного; служебные `_base`/`_kit` пропускаются |
| Анти-бот (403, капча, «проверка браузера») | не обходить; `shot_blocked: true`; описание по тексту страницы/магазина; ссылку в `check_links.py` пометить «403 — анти-бот», перепроверить обычным GET с браузерными заголовками один раз |
| Огромная страница (скриншот на десятки тысяч пикселей, тормозит) | снимать только первый экран + ключевые секции по селекторам; `fullPage` — с ограничением высоты; длинные списки — прокрутить до 2–3 экранов |
| Cookie-баннер закрывает экран | снимать как есть (это факт для аудита); для второго снимка — закрыть кнопкой «отклонить»/«закрыть», не «принять всё» |
| Ленивая загрузка — пустые блоки на скриншоте | дождаться `networkidle` и прокрутить страницу перед снимком |
| Read не открывает SVG | отрендерить SVG в PNG тем же Playwright (открыть файл, `screenshot`) во временную папку и смотреть PNG |
| В PPTX графики SVG выглядят не так или не вставляются | для колоды использовать PNG-рендер SVG (2×) — `build_deck_json.py`/`build_pptx.mjs` по своему интерфейсу; в HTML — SVG как есть |
| Кириллица в PDF — квадраты или чужой шрифт | PDF печатается Chromium из HTML-двойника колоды: шрифт с кириллицей должен быть локально доступен (системный или вложенный `@font-face` из файла); проверить первую страницу PDF глазами |
| HTML приводит `data-*` атрибуты к нижнему регистру | писать `data-marks-all`, а не `data-marksAll`; в JS читать `dataset.marksAll` |
| Конфликт имён классов в макетах | префикс классов набора (`ps-`); предупредить агентов о зарезервированных именах |
| Бейдж концепта закрывает важный элемент | позиционировать относительно свободной области экрана; проверять на PNG |
| Контраст на полупрозрачных панелях < 4,5:1 | поднять приглушённые цвета текста внутри экрана, плотнее фон панелей; где много мелкого текста — непрозрачная поверхность |

## Данные и проверки

| Проблема | Решение |
|---|---|
| `check_registry.py`: мало предложений в категории | дозаказать генератору недостающее (бриф с дырами); не ослаблять проверку и не переклассифицировать пункты ради числа |
| Ручное слияние дублей уронило минимум категории | не сливать руками в JSON: пары в `build/pairs.json` и `merge_proposals.py <OUT> --pairs build/pairs.json --auto [--pairs-winner auto]` — победитель выбирается так, чтобы минимум не упал; нарушения — в `build/merge-report.json → min_violations` |
| `merge_proposals.py` не находит семантических дублей разных групп | двухпроходная генерация (`references/orchestration.md`); `--suggest` — пары-кандидаты по убыванию сходства, решения оркестратора — в `build/pairs.json`, «похожи, но разные» — `build/merge-map.json → distinct` |
| После аудита пробелов (G7) ранги сдвинулись | G7 дописывать только `merge_proposals.py --append G7` (старые P-id сохраняются), затем `score.py`; в тексте — `{rank:P…}`/`{deprank:P…}`, а не числа |
| `check_registry.py` предупреждает о классе D без URL | для D это норма (цепочка рассуждения в `note`); в 1.1 предупреждения нет — если видите его, версия скрипта старая |
| Внешних A+B мало (предупреждение `check_registry.py`) | реестр построен «из кода»: для лучших рыночных предложений найти внешние подтверждения (конкуренты, сообщества, документация платформ); код продукта доказывает только «что есть в продукте» (`references/methodology-anchors.md`) |
| `volume: null` у всех запросов, `keywords-volume` не строится | норма без входа в инструменты: график `keywords-clusters` (кластеры × конкуренция) — запасной; объёмы — только из экспорта владельца (`sources.analytics_exports`) |
| Модель при нулевом бюджете: `CAC 0`, окупаемость 0, ROI пуст, «безубыточность» за счёт крошечных расходов | профиль `strategy.profile: zero-budget-solo` — метрики усилий (часы на активированного пользователя, часы поддержки) вместо CAC; в тексте — абсолютные суммы рядом с «безубыточностью»; `cac-ltv`/`payback` в `skipped` — не вставлять |
| Параметры модели в чужой валюте и «западные» по умолчанию | валюта, цена и трафик — из опроса (`project.currency`, `price_hint`, `traffic_hint`); ручная правка — `build/model-params.json` |
| Агенты тратят внимание на файлы выключенных направлений | `{MISSING_INPUTS}` в брифах: вычеркнуть отсутствующие входы и перечислить их (`references/orchestration.md`) |
| Агенты пишут разные факты (цены, число тестов, наличие функции) | `data/fact-check.json` (`fact, phase1_value, agent_value, source, resolved_value, note`), решение по первоисточнику и правка исходного файла — до факт-листа фазы 7 |
| Тексты стратегии в 2–3 раза длиннее минимума, повторы между разделами | `{WORDS_MAX}` (максимум = 1,5 × минимум) и таблица «Без повторов» в `references/strategy-outline.md`; приёмка однострочником объёма по разделам |
| `verdict` конкурента ломает мобильную страницу | `verdict` ≤ 45 знаков, длинное — `verdict_long` |
| Ключи функций конкурентов (snake_case) видны на графиках и в матрице | подписи — `features_labels` в `competitors.json`; ключи не переименовывать |
| Скан репозитория шумный (`venv/`, сторонний код, тысячи TODO) | `repo_scan.py` 1.1 учитывает `.gitignore` и считает TODO по отслеживаемым файлам; старый скан — перезапустить; в тексте ссылаться на числа только по отслеживаемому коду |
| Доля A+B < 60 % | искать доказательства для лучших C/D (живые функции конкурентов, документация); слабые D отбросить |
| «Длинные цитаты» — ложные срабатывания на примерах текста интерфейса | помечать примеры UI-текста словами «например:»/«текст кнопки:»; если скрипт поддерживает исключения — по его интерфейсу |
| Ничьи в рангах при валидации | это норма для одинаковых оценок; `validate_scores.py` сортирует по округлённому значению и id — расхождение только при разных исходных данных |
| Агенты дали разные факты | `references/orchestration.md` → «Расхождения агентов» |
| Выдуманный URL у агента (404, домен не существует) | удалить доказательство, понизить класс; если системно — вернуть агенту с требованием брать URL только из поиска |
| Медленный поиск, бюджет на исходе | сначала первоисточники; объединять запросы; приоритет — конкуренты и правила площадок; остаток пометить «не проверено» |
| `check_links.py` долго идёт | пауза по хосту обязательна (не снимать); запускать в фоне, пока идёт другая работа |

## Веб-страница и сборка

| Проблема | Решение |
|---|---|
| `index.html` слишком большой (> 16 МБ — не публикуется артефактом; долго открывается) | `build_html.py <OUT> --lite`: крупные картинки — файлами в `assets/` рядом со страницей (WebP при наличии кодировщика), в странице — миниатюры; цель ≤ 8 МБ. Пересылать страницу — вместе с папкой `assets/` |
| Горизонтальная прокрутка страницы | колонка контента `minmax(0,1fr)`, `main{min-width:0}`, у широких таблиц — собственная прокрутка |
| Scrollspy в smoke-тесте «не успевает» | в тестах `scrollIntoView({behavior:'instant'})` и ожидание |
| Клик по ссылке P-id открывает и лайтбокс, и модалку | в обработчике картинки исключать клики по ссылкам и тегам |
| Ссылка на предложение «битая» | P-id из текста нет в реестре после перенумерации — сверить `grep -oE 'P[0-9]{3}'` с `proposals.json`, исправить текст; `assemble_strategy.py` считает это ошибкой |
| Числа рангов в тексте устарели («ранг 8») | только `{rank:P032}` / `{deprank:P032}` — подставляет `assemble_strategy.py`; правки текста — в частях `build/parts/strategy-*.md`, затем пересборка (в готовом `strategy.md` ранги «замораживаются») |
| `![[chart:…]]` с несуществующим ключом (`funnel-aarrr`, `cac-ltv-payback`) | ключи — только из `charts.py <OUT> --list-keys` (`available`); `funnel-aarrr` → `funnel`, `cac-ltv-payback` → `cac-ltv` + `payback`; `gantt` — после записи `data/gantt.json` и `charts.py --only gantt` |
| Тексты пишутся раньше макетов, вставок макетов нет | авторы ставят `![[mockup:?P058]]`, `assemble_strategy.py --insert-mockups` разрешает маркеры и добавляет «Макеты концептов» в разделы 6–10; `link_mockups.py` — до склейки |
| `build_all` показывает `SKIP` у выключенных форматов | это «выключено выбором», не ошибка; в REPORT — раздел «Отключённое выбором» |
| Сессия оборвалась | прочитать `STRATEGY_TASKS.md` и `build/STATUS.md` (`init_run.py <OUT> --show`), продолжить с первого открытого пункта |
| Скан репозитория видит лишнее или пропускает файлы | `repo_scan.py --no-git` — обход без `git ls-files` (по умолчанию под git берутся отслеживаемые файлы); папки прошлых прогонов и venv/build пропускаются сами |
