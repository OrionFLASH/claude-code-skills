# Типичные проблемы и решения

Установка инструментов — `references/tools.md`; проверка — `python3 <SKILL_DIR>/scripts/check_env.py --out <OUT>`.

## Среда и инструменты

| Проблема | Решение |
|---|---|
| Нет Node или версия < 18 | установить по `references/tools.md`; без Node недоступны скриншоты, макеты, PPTX, PDF → собрать HTML и XLSX, остальное отметить в REPORT как сокращённое |
| Нет Playwright или Chromium | `npm i --prefix <OUT>/build/node playwright` и `npx --prefix <OUT>/build/node playwright install chromium`; не ставить глобально. Нет сети для загрузки браузера — использовать системный Chrome через `channel: 'chrome'`, если скрипт это поддерживает (`--help`), иначе браузерный MCP для ручных скриншотов |
| Скрипт не находит `playwright`/`pptxgenjs` | запускать node-скрипты с `NODE_PATH=<OUT>/build/node/node_modules`; скрипты из scratchpad модули не резолвят |
| Нет `gh` или не авторизован | Issues не читаются: пропустить `issues_export.py`, взять спрос из сообществ; уверенность «карты спроса» понижена; записать в REPORT. Владелец может выполнить `gh auth login` сам |
| Нет `TYPESAFE_API_KEY` | `typesafe_eval.py` пишет `skipped` и выходит без ошибки; колонка TypeSafe в результатах пустая с пометкой; модель субагентов — по правилу из `references/orchestration.md` |
| Нет скилла `typesafe-triage` | правило по умолчанию: сбор/механика — sonnet, синтез/дизайн/оценка — opus |
| `CERTIFICATE_VERIFY_FAILED` в Python | системные сертификаты не подхвачены: на macOS — `Install Certificates.command` от установщика Python; иначе `SSL_CERT_FILE` на файл CA-бандла системы |
| `python3 -I` ломает импорт библиотек | `-I` — только для скриптов, читающих недоверенные файлы; генераторы графиков запускать без `-I` |
| zsh: `no matches found` на `--include=*.html` | брать glob в кавычки: `--include='*.html'` |
| `grep -c` вернул 0 и оборвал цепочку `&&` | проверки с ненулевым кодом не ставить в середину цепочки; использовать `;` или `|| true` |
| Ключ мелькнул в выводе | никогда не грепать файлы настроек целиком; ключ отозвать/сменить (сказать владельцу), проверить, что его нет в `<OUT>` |
| Папка прогона «не там», где ждал владелец | место папки фиксируется в опросе; в начале фазы 0 показать путь к главному результату |

## Приложение и браузер

| Проблема | Решение |
|---|---|
| Приложение не запускается локально | 3–4 попытки (README, Makefile, Docker, `package.json`), затем публичный адрес; нет и его — по коду с пометкой «уверенность понижена»; причину — в STATUS и REPORT |
| Нужен вход в аккаунт | только тестовые учётки из фикстур проекта; иначе пройти путь до формы входа и описать остальное по коду |
| Анти-бот (403, капча, «проверка браузера») | не обходить; `shot_blocked: true`; описание по тексту страницы/магазина; ссылку в `check_links.py` пометить «403 — анти-бот», перепроверить обычным GET с браузерными заголовками один раз |
| Огромная страница (скриншот на десятки тысяч пикселей, тормозит) | снимать только первый экран + ключевые секции по селекторам; `fullPage` — с ограничением высоты; длинные списки — прокрутить до 2–3 экранов |
| Cookie-баннер закрывает экран | снимать как есть (это факт для аудита); для второго снимка — закрыть кнопкой «отклонить»/«закрыть», не «принять всё» |
| Ленивая загрузка — пустые блоки на скриншоте | дождаться `networkidle` и прокрутить страницу перед снимком |
| Read не открывает SVG | отрендерить SVG в PNG тем же Playwright (открыть файл, `screenshot`) во временную папку и смотреть PNG |
| В PPTX графики SVG выглядят не так или не вставляются | для колоды использовать PNG-рендер SVG (2×) — `build_deck_json.py`/`build_pptx.mjs` по своему интерфейсу; в HTML — SVG как есть |
| Кириллица в PDF — квадраты или чужой шрифт | PDF печатается Chromium из HTML-двойника колоды: шрифт с кириллицей должен быть локально доступен (системный или вложенный `@font-face` из файла); проверить первую страницу PDF глазами |
| HTML приводит `data-*` атрибуты к нижнему регистру | писать `data-marks-all`, а не `data-marksAll`; в JS читать `dataset.marksAll` |
| Конфликт имён классов в макетах | префикс классов набора (`ps-`); предупредить агентов о зарезервированных именах |
| Бейдж концепта закрывает важный элемент | позиционировать относительно свободной области экрана; проверять на PNG |
| Контраст на полупрозрачных панелях < 4,5:1 | поднять приглушённые цвета текста внутри экрана, плотнее фон панелей; где много мелкого текста — непрозрачная поверхность |

## Данные и проверки

| Проблема | Решение |
|---|---|
| `check_registry.py`: мало предложений в категории | дозаказать генератору недостающее (бриф с дырами); не ослаблять проверку и не переклассифицировать пункты ради числа |
| Доля A+B < 60 % | искать доказательства для лучших C/D (живые функции конкурентов, документация); слабые D отбросить |
| «Длинные цитаты» — ложные срабатывания на примерах текста интерфейса | помечать примеры UI-текста словами «например:»/«текст кнопки:»; если скрипт поддерживает исключения — по его интерфейсу |
| Ничьи в рангах при валидации | это норма для одинаковых оценок; `validate_scores.py` сортирует по округлённому значению и id — расхождение только при разных исходных данных |
| Агенты дали разные факты | `references/orchestration.md` → «Расхождения агентов» |
| Выдуманный URL у агента (404, домен не существует) | удалить доказательство, понизить класс; если системно — вернуть агенту с требованием брать URL только из поиска |
| Медленный поиск, бюджет на исходе | сначала первоисточники; объединять запросы; приоритет — конкуренты и правила площадок; остаток пометить «не проверено» |
| `check_links.py` долго идёт | пауза по хосту обязательна (не снимать); запускать в фоне, пока идёт другая работа |

## Веб-страница и сборка

| Проблема | Решение |
|---|---|
| `index.html` слишком большой (> 30 МБ) | скриншоты/макеты — WebP, превью отдельно от полного размера, каждая картинка встроена один раз (по ключу); графики — SVG |
| Горизонтальная прокрутка страницы | колонка контента `minmax(0,1fr)`, `main{min-width:0}`, у широких таблиц — собственная прокрутка |
| Scrollspy в smoke-тесте «не успевает» | в тестах `scrollIntoView({behavior:'instant'})` и ожидание |
| Клик по ссылке P-id открывает и лайтбокс, и модалку | в обработчике картинки исключать клики по ссылкам и тегам |
| Ссылка на предложение «битая» | P-id из текста нет в реестре после перенумерации — сверить `grep -oE 'P[0-9]{3}'` с `proposals.json`, исправить текст |
| Сессия оборвалась | прочитать `TASKS.md` и `build/STATUS.md`, продолжить с первого открытого пункта |
