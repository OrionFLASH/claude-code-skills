# Обновление typesafe-triage

Для тех, кто уже поставил скилл ([INSTALL.md](INSTALL.md)). Ключ, журнал, потолок расходов и состояние лежат вне папки скилла (`~/.claude/typesafe-triage/`, Windows: `%USERPROFILE%\.claude\typesafe-triage\`) и при обновлении сохраняются.

Обновить нужно три вещи, а не одну: **файлы скилла**, **хук** в `settings.json` и **правила в `CLAUDE.md`**. Без двух последних новые возможности (effort, подтверждения, запасные способы) работать не будут.

## Быстрый способ: промпт для Claude Code

Вставьте в Claude Code на своей машине. Он сам найдёт установку, спросит что нужно, обновит всё три части и проверит результат.

````text
Обнови на этой машине скилл typesafe-triage до последней версии из публичного репозитория
https://github.com/OrionFLASH/claude-code-skills (папка skills/typesafe-triage), приведи
хук и правила в CLAUDE.md в актуальное состояние и проверь результат.
Ориентируйся на UPDATE.md и INSTALL.md в этой папке. Отвечай мне по-русски.

ПРАВИЛА
- Сначала разведка (только чтение), потом вопросы, затем действия.
- Ничего не удаляй: старую копию скилла переименуй в *.bak-ГГГГММДД. Перед правкой settings.json
  и CLAUDE.md сделай резервную копию рядом (файл.bak-ГГГГММДД) и покажи, что изменишь. JSON правь
  аккуратно (читай, дополняй, ничего не затирай, проверь парсером). В CLAUDE.md меняй только
  раздел про триаж, остальное содержимое не трогай.
- Ключ TypeSafe не печатай и не проси присылать в чат; существующий ключ не трогай. Если ключа
  нет - скажи, где его взять (https://console.typesafe.ai) и куда вписать, сам не придумывай.
- Если права Claude Code не разрешают правку settings.json или CLAUDE.md, не обходи запрет:
  покажи точный текст, я вставлю сам.

ШАГ 0. РАЗВЕДКА (только чтение)
1) Скилл: где и как стоит (~/.claude/skills/typesafe-triage - симлинк или папка, для симлинка
   покажи куда ведёт; .claude/skills проекта; плагин из маркетплейса - claude plugin list;
   клон репозитория). Текущая версия (.claude-plugin/plugin.json) и последняя в репозитории
   (CHANGELOG.md, теги typesafe-triage/v*). Если версия последняя - файлы не трогай, но
   остальные проверки шагов 0, 3 и 4 всё равно выполни.
2) Хук: в settings.json (глобальном и проектном) найди хук typesafe_triage.py --hook: путь, есть ли
   timeout (нужно не меньше 10). Нет ли дубля: ручной хук и хук плагина (hooks/hooks.json) вместе.
3) CLAUDE.md (глобальный и проектный): есть ли раздел про триаж модели, актуален ли он (должен
   содержать правила про effort и про подтверждение haiku/fable/low/max - см. шаблон ниже).
4) Ключ: есть ли TYPESAFE_API_KEY в settings.json -> env или окружении (только факт).
5) Среда: ОС, рабочая команда Python 3 (python3, python, py -3).
6) Возможности Claude Code: есть ли у ТВОЕГО инструмента Agent параметр effort (посмотри схему
   своих инструментов). Запомни ответ и сообщи мне - от этого зависит текст пояснения в итоге.
Покажи краткую сводку.

ШАГ 1. ВОПРОСЫ (мне; через AskUserQuestion, по 1-3 за раз)
1) Обновить файлы скилла с версии X до Y?
2) Способ обновления (предложи подходящий по разведке): git pull в клоне, замена копии,
   обновление плагина из маркетплейса.
3) Если найден дубль хука - какой оставить? (рекомендация: для установки плагином - хук плагина,
   для клона или копии - ручной хук в settings.json).
4) CLAUDE.md: глобальный (для всех проектов), только проектный или не трогать? Заменить/добавить
   раздел «Триаж модели и effort» по шаблону ниже?

ШАГ 2. ОБНОВЛЕНИЕ ФАЙЛОВ
- Симлинк на клон: git pull в клоне.
- Копия: переименуй старую папку в *.bak-ГГГГММДД, скопируй новую папку скилла без __pycache__.
- Маркетплейс: claude plugin marketplace update claude-code-skills, затем
  claude plugin update typesafe-triage@claude-code-skills (потом нужен перезапуск Claude Code).
- Не оставляй копии скилла в двух местах (например, и в ~/.claude/skills, и плагином).

ШАГ 3. ХУК
- Хук должен вызывать актуальный typesafe_triage.py --hook: <рабочий python> "<полный путь>" --hook,
  событие UserPromptSubmit, timeout 10. На Windows - прямые слеши и полный путь вместо $HOME.
- Если хука нет - добавь его (блок есть в INSTALL.md); если путь вёл в старую версионную папку
  плагина или timeout меньше 10 - поправь; если выбрано убрать дубль - оставь один.
  Остальное в settings.json не трогай.

ШАГ 4. ПРАВИЛА В CLAUDE.md (если я согласился в вопросе 4)
- Если раздела про триаж нет - добавь в конец файла. Если есть, но он устарел (нет правил про
  effort или про подтверждение крайних уровней) - замени этот раздел целиком на шаблон ниже.
  Сохрани мои собственные пункты, которых нет в шаблоне, если они не противоречат ему.
Шаблон раздела:
```markdown
## Триаж модели и effort (TypeSafe)
- Если в запросе есть заметка «TypeSafe-триаж», выполняй её всегда, без напоминаний.
- Содержательная работа, где уровень выше моей модели, или большая изолируемая задача: Agent с model=<уровень> и самодостаточным промптом.
- Effort по заметке: если у Agent есть параметр effort — Agent(model=<уровень>, effort=<effort>), это моё явное требование (параметр ставится только по явной просьбе пользователя, CLAUDE.md или скилла). Если параметра нет — не ссылайся на него (это не ошибка): глубину задай фразой в промпте агента из заметки, а когда заметка предлагает `--run` и работа изолируемая — запусти её так.
- Уровни haiku и fable, effort low и max — только после подтверждения через AskUserQuestion (один вопрос на обе оси); нет «да» → sonnet/opus, medium/xhigh. Явное указание в моём запросе («на opus», «effort max», «тщательно») — уже согласие.
- Субагентам скилл typesafe-triage не применять.
```

ШАГ 5. ПРОВЕРКА
- Версия после обновления совпадает с последней.
- Запусти: <python> <путь>/typesafe_triage.py --check (ключ не печатай). Если стоит пауза -
  покажи --status и спроси, снять ли (--resume).
- Проверь хук: echo '{"prompt":"Подготовь план миграции базы данных с проверкой отката","cwd":".","session_id":"upd1"}' | <python> <путь>/typesafe_triage.py --hook
  В JSON должна быть заметка «TypeSafe-триаж: уровень … effort …».
- Офлайн-тесты, если установлен pytest: <python> -m pytest <путь>/scripts -q -p no:cacheprovider
- Итоговая таблица «что должно быть» (по каждой строке: ОК / исправлено / требует моих действий):
  версия скилла; хук (один, актуальный путь, timeout >= 10); раздел в CLAUDE.md; ключ; заметка
  в выводе хука; нет дублей скилла.
- Что мне сделать вручную: перезапустить Claude Code (иначе обновлённое описание скилла и хук не
  подхватятся), вписать ключ, если его не было. Как откатить (вернуть .bak, убрать изменённые блоки).
- Если у моего Agent нет параметра effort - объясни, что effort будет задаваться фразой в
  промпте агента или запуском через typesafe_triage.py --run, и что это нормально.
````

## Вручную

**Версия сейчас:**

```text
# macOS / Linux
grep '"version"' ~/.claude/skills/typesafe-triage/.claude-plugin/plugin.json
# Windows (PowerShell)
Select-String '"version"' $HOME\.claude\skills\typesafe-triage\.claude-plugin\plugin.json
```

**1. Файлы скилла (по тому, как ставили):**

| Установка | Команды |
|---|---|
| Клон + симлинк (macOS / Linux) | `cd ~/dev/claude-code-skills && git pull` |
| Клон + копирование | `git pull` в клоне, затем переименовать старую папку скилла в `typesafe-triage.bak` и скопировать новую из `skills/typesafe-triage` |
| Маркетплейс | `/plugin marketplace update claude-code-skills`, затем `/plugin update typesafe-triage@claude-code-skills` (или `claude plugin update typesafe-triage@claude-code-skills`), перезапуск Claude Code |
| ZIP | скачать репозиторий заново, заменить папку `skills/typesafe-triage` в `~/.claude/skills/` |

**2. Хук** в `settings.json` (`~/.claude/settings.json`, Windows: `%USERPROFILE%\.claude\settings.json`): один хук `UserPromptSubmit` на `typesafe_triage.py --hook`, `timeout` не меньше 10. Готовые блоки для macOS/Linux и Windows — в [INSTALL.md](INSTALL.md). При установке плагином хук приносит сам плагин, ручной тогда не нужен (иначе их будет два).

**3. Раздел в `CLAUDE.md`** (`~/.claude/CLAUDE.md`, Windows: `%USERPROFILE%\.claude\CLAUDE.md`): замените старый раздел про триаж модели на этот (или добавьте, если его не было):

```markdown
## Триаж модели и effort (TypeSafe)
- Если в запросе есть заметка «TypeSafe-триаж», выполняй её всегда, без напоминаний.
- Содержательная работа, где уровень выше моей модели, или большая изолируемая задача: Agent с model=<уровень> и самодостаточным промптом.
- Effort по заметке: если у Agent есть параметр effort — Agent(model=<уровень>, effort=<effort>), это моё явное требование (параметр ставится только по явной просьбе пользователя, CLAUDE.md или скилла). Если параметра нет — не ссылайся на него (это не ошибка): глубину задай фразой в промпте агента из заметки, а когда заметка предлагает `--run` и работа изолируемая — запусти её так.
- Уровни haiku и fable, effort low и max — только после подтверждения через AskUserQuestion (один вопрос на обе оси); нет «да» → sonnet/opus, medium/xhigh. Явное указание в моём запросе («на opus», «effort max», «тщательно») — уже согласие.
- Субагентам скилл typesafe-triage не применять.
```

**4. Проверка:**

```text
# macOS / Linux
python3 ~/.claude/skills/typesafe-triage/scripts/typesafe_triage.py --check
# Windows (PowerShell)
python $HOME\.claude\skills\typesafe-triage\scripts\typesafe_triage.py --check
```

Должны быть «ключ: есть» и ответ сервиса. Перезапустите Claude Code и отправьте любую задачу длиннее 40 символов: в заметке должно быть «уровень <модель>, effort <уровень>».

**Если стоит пауза** (после сбоев сервиса или нехватки средств): `… typesafe_triage.py --status`, затем `--resume`.

## Что должно получиться

| Что | Признак |
|---|---|
| Файлы скилла | `plugin.json` показывает последнюю версию, дубля скилла нет |
| Хук | один хук `UserPromptSubmit`, путь актуальный, `timeout` не меньше 10 |
| `CLAUDE.md` | раздел «Триаж модели и effort (TypeSafe)» по шаблону выше |
| Ключ | `TYPESAFE_API_KEY` в `env` или окружении, `--check` отвечает |
| Работа | в запросах появляется заметка «TypeSafe-триаж: уровень …, effort …» |

## Если у вашего `Agent` нет параметра effort
Это нормально: заметка тогда советует задать глубину фразой в промпте агента, а для ответственной изолируемой работы — запустить её командой `--run --effort …`, которую заметка показывает готовой.

## Откат
Верните переименованную папку `typesafe-triage.bak` на место, а из `settings.json` и `CLAUDE.md` — резервные копии `.bak-ГГГГММДД`. При установке из клона нужную версию можно взять по тегу `typesafe-triage/v<версия>`. Ключ и журнал откат не затрагивает.
