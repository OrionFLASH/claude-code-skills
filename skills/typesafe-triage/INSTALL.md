# Установка и обновление typesafe-triage

Скилл выбирает для каждой задачи две независимые вещи — уровень модели Claude (haiku / sonnet / opus / fable) и reasoning effort (low / medium / high / xhigh / max) — через TypeSafe и локальные сигналы и подсказывает Claude, кому и как её делегировать (`Agent(model=…, effort=…)`). Работает через хук `UserPromptSubmit`. При установке **плагином из маркетплейса** хук приходит вместе с плагином (`hooks/hooks.json`); при установке **копией или симлинком** хук прописывается вручную.

Одна инструкция для macOS, Linux и Windows: [установка](#установка) и [обновление](#обновление). У рабочей установки три части — **файлы скилла**, **хук** в `settings.json` и **правила в `CLAUDE.md`**; при обновлении приводятся в порядок все три, иначе новые возможности (effort, подтверждения, запасные способы) работать не будут. Ключ, журнал, потолок расходов и состояние лежат вне папки скилла (`~/.claude/typesafe-triage/`, Windows: `%USERPROFILE%\.claude\typesafe-triage\`) и при обновлении сохраняются.

## Быстрый способ: попросите Claude Code всё сделать за вас

Откройте Claude Code в любой папке и вставьте нужный промпт целиком. Claude сам определит ОС, задаст вопросы (куда и как ставить), поставит или обновит скилл, пропишет хук и проверит работу. Ключ в чат присылать не нужно: его вы вставляете сами в файл настроек (Claude покажет, куда).

## Установка

### Шаг 1. Поставить скилл (один из способов)

**Способ 1. Маркетплейс** (в Claude Code, любая ОС):

```text
/plugin marketplace add OrionFLASH/claude-code-skills
/plugin install typesafe-triage@claude-code-skills
```

Файлы лежат в `~/.claude/plugins/cache/…/typesafe-triage/<версия>/`; **эта папка меняется при обновлении**. Хук плагина ссылается на неё через `${CLAUDE_PLUGIN_ROOT}`, поэтому при обновлении ничего править не нужно, и **шаг 3 (ручной хук) для этого способа пропустите**.

**Способ 2. Клонирование (постоянный путь, рекомендуется для хука)**

macOS / Linux:

```bash
git clone https://github.com/OrionFLASH/claude-code-skills.git ~/dev/claude-code-skills
cd ~/dev/claude-code-skills && tools/install.sh typesafe-triage
```

Windows (PowerShell) — junction на клон (как симлинк: `git pull` подхватывается сразу, права администратора не нужны) или копия:

```powershell
git clone https://github.com/OrionFLASH/claude-code-skills.git $HOME\dev\claude-code-skills
cd $HOME\dev\claude-code-skills
powershell -ExecutionPolicy Bypass -File tools\install.ps1 typesafe-triage
# или копией:
# New-Item -ItemType Directory -Force $HOME\.claude\skills | Out-Null
# Copy-Item -Recurse $HOME\dev\claude-code-skills\skills\typesafe-triage $HOME\.claude\skills\typesafe-triage
```

**Способ 3. Архив:** скачайте репозиторий как ZIP на GitHub и скопируйте папку `skills/typesafe-triage` в `~/.claude/skills/` (Windows: `%USERPROFILE%\.claude\skills\`).

Не ставьте один и тот же скилл двумя способами одновременно — будет дубль.

### Шаг 2. Ключ

Ключ задаётся переменной окружения `TYPESAFE_API_KEY`. Самый простой и переносимый путь — файл настроек Claude Code:

| ОС | Файл |
|---|---|
| macOS / Linux | `~/.claude/settings.json` |
| Windows | `%USERPROFILE%\.claude\settings.json` |

```json
{
  "env": {
    "TYPESAFE_API_KEY": "ваш_ключ"
  }
}
```

Если блок `env` уже есть, допишите строку в него. Ключ нигде не публикуйте и не коммитьте. Альтернатива — системная переменная окружения (Windows: `setx TYPESAFE_API_KEY "ваш_ключ"`, затем перезапустить Claude Code).

### Шаг 3. Хук (без него заметки «TypeSafe-триаж» не появятся)

**Плагин из маркетплейса (способ 1)** приносит хук сам — этот шаг не нужен. **Копия или ссылка (способы 2 и 3)** хук не добавляют: впишите его в тот же файл `settings.json`:

macOS / Linux, способ 2 через `tools/install.sh` или копия:

```json
{
  "hooks": {
    "UserPromptSubmit": [
      { "hooks": [ {
        "type": "command",
        "command": "python3 \"$HOME/.claude/skills/typesafe-triage/scripts/typesafe_triage.py\" --hook",
        "timeout": 10
      } ] }
    ]
  }
}
```

Windows (имя пользователя подставьте своё, слеши прямые):

```json
{
  "hooks": {
    "UserPromptSubmit": [
      { "hooks": [ {
        "type": "command",
        "command": "python \"C:/Users/ИМЯ/.claude/skills/typesafe-triage/scripts/typesafe_triage.py\" --hook",
        "timeout": 10
      } ] }
    ]
  }
}
```

Если блок `hooks`/`UserPromptSubmit` уже есть, добавьте элемент в существующий массив, а не заводите второй блок. Хук должен быть один, `timeout` — не меньше 10.

#### Хук плагина (`hooks/hooks.json`) — что проверено
- Корень плагина — папка скилла (`"skills": ["./"]`), хук лежит по стандартному пути `hooks/hooks.json` (формат с обёрткой `"hooks"`, событие `UserPromptSubmit`, `timeout` 10, путь через `${CLAUDE_PLUGIN_ROOT}`). Проверено: `claude plugin validate skills/typesafe-triage` — «Validation passed» (валидатор действительно разбирает `hooks/hooks.json`: испорченный файл он отклоняет), и живой запуск `claude -p --plugin-dir skills/typesafe-triage` (Claude Code 2.1.292) — хук плагина сработал, заметка попала в контекст. Установку именно из маркетплейса (`/plugin install`) отдельно не проверяли — загрузчик плагинов тот же.
- Команда хука: `python3 "…/typesafe_triage.py" --hook || python "…/typesafe_triage.py" --hook`. Скрипт всегда завершается с кодом 0, поэтому `python` запускается, только если `python3` нет или он не запустился (на Windows с установщиком python.org обычно есть только `python` и `py`). Отдельный скрипт-запускатель не добавлен: чтобы его запустить, всё равно нужен интерпретатор, а цепочка `||` решает задачу без лишнего файла.
- На Windows команды хуков выполняются в Git Bash; без него — в PowerShell, где `||` работает только в PowerShell 7+. В Windows PowerShell 5.1 без Git Bash хук плагина не сработает — тогда отключите плагинный хук и пропишите ручной, как выше (`python` или `py -3`).
- Если хук окажется и в `settings.json`, и в плагине, выполнятся **оба**, но заметка будет одна: второй вызов на тот же запрос (тот же `session_id` и текст, в пределах 8 с) молчит. Всё равно лучше оставить один: для установки плагином — хук плагина, для клона или копии — ручной.
- Отправку в TypeSafe плагинный хук включает только при наличии `TYPESAFE_API_KEY`; без ключа работают локальные сигналы, в сеть ничего не уходит.

Перезапустите Claude Code и выполните:

python3 ~/.claude/skills/typesafe-triage/scripts/typesafe_triage.py --check

### Шаг 5. Правила в CLAUDE.md (по желанию — применение без напоминаний)

Добавьте в `~/.claude/CLAUDE.md` (Windows: `%USERPROFILE%\.claude\CLAUDE.md`), а при обновлении замените этим текстом старый раздел про триаж модели. Строка про effort условная: параметр `effort` у инструмента `Agent` есть не во всех версиях Claude Code. Если его нет, Claude может написать «effort передать не могу» — это нормально: модель по заметке всё равно выбирается, а глубина задаётся фразой в промпте агента или запуском `--run` (подробно — [references/effort.md](references/effort.md#когда-у-agent-нет-параметра-effort)).

```markdown
## Триаж модели и effort (TypeSafe)
- Если в запросе есть заметка «TypeSafe-триаж», выполняй её всегда, без напоминаний.
- Содержательная работа, где уровень выше моей модели, или большая изолируемая задача: Agent с model=<уровень> и самодостаточным промптом.
- Effort по заметке: если у Agent есть параметр effort — Agent(model=<уровень>, effort=<effort>), это моё явное требование (параметр ставится только по явной просьбе пользователя, CLAUDE.md или скилла). Если параметра нет — не ссылайся на него (это не ошибка): глубину задай фразой в промпте агента из заметки, а когда заметка предлагает `--run` и работа изолируемая — запусти её так.
- Уровни haiku и fable, effort low и max — только после подтверждения через AskUserQuestion (один вопрос на обе оси); нет «да» → sonnet/opus, medium/xhigh. Явное указание в моём запросе («на opus», «effort max», «тщательно») — уже согласие.
- Субагентам скилл typesafe-triage не применять.
```

Это нормально: заметка тогда советует задать глубину фразой в промпте агента, а для ответственной изолируемой работы — запустить её командой `--run --effort …`, которую заметка показывает готовой.

## Приватность и выключатели
- В TypeSafe уходит дайджест каждого запроса длиннее 40 символов (до 4500 знаков; ключи, токены и пароли заменяются на «[скрыто]»). Файлы проекта не отправляются.
- Отключить в проекте: пустой файл `.typesafe-triage-off` в папке проекта. Отключить везде: переменная `TYPESAFE_TRIAGE=off`.
- Состояние, журнал и потолок расходов: `~/.claude/typesafe-triage/` (Windows: `%USERPROFILE%\.claude\typesafe-triage\`). Статус: `… typesafe_triage.py --status`.

## Если не работает
| Симптом | Что проверить |
|---|---|
| Заметок нет | хук в `settings.json` или включённый плагин, перезапуск Claude Code, `--check`, запрос длиннее 40 символов |
| В заметке нет effort | старая версия скилла (до 2.1) — обновите (раздел «Обновление») |
| Claude пишет, что effort для агента передать не может | у `Agent` в вашей версии нет параметра `effort` — это не ошибка; с 2.1.2 заметка даёт фразу глубины для промпта и, для критичных задач, команду `--run` |
| «Задано пользователем» из-за слов в кавычках | с 2.1.2 маркеры в кавычках, коде, пересказе и вставленных отчётах не считаются указаниями; обновите скилл |
| «ключ: нет» | `TYPESAFE_API_KEY` в `env` или в окружении |
| На Windows хук молчит | `python` в PATH; попробуйте `py -3` в команде хука; полный путь с прямыми слешами |
| Хук прописан дважды (ручной и плагина) | заметка всё равно одна, но оставьте один: для плагина — хук плагина, для клона или копии — ручной |
| Пауза / нет средств | `--status`, пополнить баланс на console.typesafe.ai, затем `--resume` |
| Ошибка сертификатов | `--check`: у сборки Python может не быть корневых сертификатов |
