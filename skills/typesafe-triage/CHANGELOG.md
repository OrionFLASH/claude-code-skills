# Журнал изменений typesafe-triage

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — SemVer, теги `typesafe-triage/vX.Y.Z`.

## [2.1.1] — 2026-10-08
Устойчивость к всплескам задержки TypeSafe (замер: медиана ответа ~0.7 с, но бывают всплески 5-20 с и ответы 5xx/529).
### Изменено
- Таймаут хука 3 → 5 с (бюджет хука в `settings.json` — 10 с).
- Один быстрый повтор запроса при 500/502/503/504/529, если в бюджете остаётся ≥ 1,5 с (`ask_with_retry`).
- Первая временная пауза после сбоя сервиса 5 мин → 1 мин (дальше ×2 до 1 ч): единичный всплеск больше не отключает совет на 5 минут.
- Тесты обновлены, добавлены тесты повтора (161 тест).

## [2.1.0] — вторая ось: reasoning effort
### Добавлено
- Вторая независимая ось `effort` (`low < medium < high < xhigh < max`) рядом с моделью; модуль `scripts/triage_effort.py`. Полоса без вопросов — `medium..xhigh` (при сомнении `high`); `low` и `max` — только с подтверждения (`CONFIRM_EFFORTS`), без него `low → medium`, `max → xhigh`; `xhigh` вынесен в `OPTIONAL_CONFIRM_EFFORTS`.
- Слоистая оценка с прозрачными причинами (`effort_reasons`): a) TypeSafe — новые вопросы в том же запросе (`planning`, `shallow_cost`, `verification`, `exploration`, `constraints`, `coordination`) плюс прежние шкалы; b) текст — намерение, требования, критерии приёмки, ограничения, неопределённость, диагностика, критичность, объём, математика; c) окружение — git, тесты, CI, lock-файлы, порядок числа файлов, маркер `.typesafe-triage-effort` (локально); d) история сессии — повторы после неудачи поднимают effort (потолок +2, не до max) и при втором повторе модель (не выше opus); e) правила согласованности модель × effort; f) запасной вариант без TypeSafe.
- Явные указания пользователя в тексте («на opus», «effort max», «ultrathink», «тщательно», «кратко», "use haiku", "think hard"…) — согласие и приоритет над автооценкой, с учётом отрицаний.
- Заметка хука: пара «модель + effort», один `AskUserQuestion` на обе оси, `Agent(model=…, effort=…)`, строка `/effort …` для основной сессии (если её effort известен и отличается на ≥ 2 ступени), один уточняющий вопрос при неуверенной оценке и высокой цене ошибки.
- `--run`: `--effort`, `--confirmed-effort`, передача `claude -p --effort`; `--dry-run` показывает effort. Неизвестный effort отклоняется (CLI сам его молча игнорирует — проверено).
- Идемпотентность хука: второй вызов на тот же запрос (`session_id` + хеш промпта) в течение 8 с молчит — ручной хук и хук плагина не дают двух заметок.
- Хук плагина `hooks/hooks.json` (`${CLAUDE_PLUGIN_ROOT}`, запуск `python3`, при отсутствии — `python`); проверено `claude plugin validate` и живым запуском `--plugin-dir`.
- `--calibrate` (распределение effort, матрица «ожидаемый → выданный», сводка журнала, `--split train|holdout`, `--cache`); `triage_cases.json` расширен до 82 кейсов (15 областей, ru/en, явные указания, отрицания, история) с ожидаемыми диапазонами `effort_ok`/`tier_ok`.
- Документация `references/effort.md`; живая проверка сочетаний `claude -p --model haiku|sonnet|opus --effort <все 5>` (все приняты).

### Изменено
- Результат триажа дополнен полями `effort`, `effort_confidence`, `effort_confirm`, `effort_fallback`, `effort_source`, `effort_reasons`, `effort_depth`, `effort_layers`, `model_source`, `explicit`, `clarify`, `retry`, `env`, `session` (формат аддитивный, старые поля сохранены); журнал — effort, источник, хеш сессии, признак повтора.
- Запасной вариант модели без TypeSafe: opus также при ≥ 2 группах слов риска (без условия объёма), при намерении «доказать» и при риске + намерении не легче «проверить/сравнить». Словари сигналов расширены (кредит/ипотека/оценка/инвесторы, учётные данные, лекарства/закон, «периодически», 5xx); «переезд» считается риском только для баз/серверов/систем.
- Заметка начинается с «TypeSafe-триаж: уровень X, effort Y (…)».

## [2.0.0] — универсальный триаж и четыре уровня
### Изменено (несовместимо)
- Триаж универсальный: оцениваются любые задачи (код, документы, письма, анализ, данные, исследование, планирование, ревью, ops). Вопрос `software_dev` и правило «молчать вне разработки» удалены; пропускаются только короткие реплики/подтверждения, команды `/…` и служебные сообщения среды.
- Уровни `haiku < sonnet < opus < fable` (`TIERS`). haiku и fable никогда не запускаются автоматически (`CONFIRM_TIERS`): заметка требует `AskUserQuestion`, без «да» — sonnet/opus. В `--run` и `--tier` они допускаются только с новым флагом `--confirmed`; `build_agent_cmd` без `confirmed=True` их отклоняет.
- Вопросы к TypeSafe переписаны доменно-нейтрально по документации (уровни-ситуации с примерами): шкалы `complexity`, `reasoning`, `ambiguity`, `risk` (4 уровня, верхний — критично/необратимо), новая `breadth`; флаги `read_only`, `mechanical`, `needs_investigation`, `silent_errors` (вместо `touches_data_rules`), новые `irreversible`, `novel_design`, `conversational`; Choice `domain` (для заметки и журнала).
- Формат результата: `model` есть всегда; новые поля `source` (`typesafe`/`heuristic`), `confidence`, `confirm`, `fallback`, `skip`, `signals`, `domain`; поле `dev` удалено.
- Заметка хука — короткая и императивная: когда делегировать (`Agent(model=…)`), когда делать самому, вопрос пользователю для haiku/fable.
- Журнал пишет все оценённые запросы (не только разработку), реплики не пишутся.

### Добавлено
- Локальные эвристики `scripts/triage_heuristics.py`: длина, пункты, перечисления, шаги, файлы, код/логи, слова критичности (прод, необратимость, безопасность, деньги, юридическое/медицинское, потеря данных), «глубокие» и «лёгкие» слова. Только поднимают нагрузку, могут запретить haiku, должны подтвердить fable.
- Запасной вариант: без ответа TypeSafe (нет ключа, сеть, пауза защиты, слишком большой вход) уровень по эвристике — только sonnet/opus с пометкой «уверенность низкая».
- Ворота haiku по вероятности верхней половины шкал (из `probabilities`), шаг вверх за низкую уверенность — только у границы уровня.
- Команды `--signals`, `--selftest --heuristic`; `triage_cases.json` с универсальными кейсами (письма, планы, анализ, стратегия, договор, финмодель, fable, реплики).
- `references/`: `levels.md`, `guard.md`, `privacy.md`, `superpowers.md`.

### Сохранено
- Путь `~/.claude/skills/typesafe-triage/scripts/`, публичное API `typesafe_guard`, CLI-команды, хук-протокол (JSON на stdout, никогда не блокирует, ошибка = молчание), файлы состояния, выключатели, `TYPESAFE_TRIAGE_CHILD`, маскировка секретов, дайджест.
