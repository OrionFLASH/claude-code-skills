# Как выбирается действие: сам, Agent или спросить (2.3)

Модель и effort говорят, **что нужно задаче**. Действие говорит, **кому выгоднее её делать**: основной сессии, субагенту или сначала спросить пользователя. Решает код (`scripts/triage_action.py`, функция `decide`) по полям результата триажа, признакам текста (`triage_heuristics.action_signals`) и сведениям о сессии (`triage_session.session_info`). Без сети, детерминированно.

## Формат заметки

```text
ДЕЙСТВИЕ: <сам | Agent(model=…, effort=…) | спросить> — <одна причина, не больше 15 слов>. Уверенность: <высокая|средняя|низкая|унаследована>. [TypeSafe-триаж: <модель>/<effort>; <TypeSafe|только эвристика>; тип <…>; id <…>]
• … только нужные пункты
```

- **Уверенность одна** на всю оценку: эвристика — «низкая», наследование — «унаследована», иначе меньшая из уверенностей модели и effort.
- **Пункты** (по одному, только когда нужны): подтверждение одним `AskUserQuestion`; «Задано пользователем»; как передать effort (только при делегировании); общее интерактивное состояние; долгое ожидание; параллельные части; `/effort` для основной сессии (только «сам»); правила для исполнителя (только при делегировании).
- Числа осей, нагрузка, слои effort — в JSON (`--signals`, `"текст"`) и в журнале, не в заметке.

## Правила (сверху вниз, первое сработавшее решает)

| № | Условие | Действие | Причина в заметке |
|---|---|---|---|
| 1 | пользователь просит сделать самому / без субагента | сам | «пользователь просит сделать самому, без субагента» |
| 2 | неуверенная оценка при высокой цене ошибки (`clarify`) | спросить | «… ОДИН короткий уточняющий вопрос» |
| 3 | долгое ожидание (минуты-часы) | сам | «долгое ожидание — фоновый скрипт и проверка, а не субагент» |
| 4 | пользователь просит субагента | Agent | «пользователь просит субагента — делегируй» |
| · | короткое продолжение с унаследованной оценкой | то же, что в прошлый раз | «продолжение предыдущей задачи — решение прежнее» |
| 5 | общее устройство или сессия | сам | «общее устройство или сессия — одно взаимодействие за раз» |
| 6 | небольшая задача или диалог | сам | «небольшая задача или диалог — быстрее самому» |
| 7 | нужный уровень выше модели сессии | Agent | «нужен opus, а модель сессии sonnet ниже» (+ «(по настройкам)», если модель из settings.json) |
| 8 | модель сессии неизвестна, нужен opus или выше | Agent | «нужен opus; модель сессии хуку неизвестна — если ты уже opus или выше, делай сам» |
| 9 | большая изолируемая задача, контекст передаётся недорого | Agent | «большая изолируемая задача — субагент сбережёт контекст сессии» |
| 10 | продолжение с накопленным контекстом | сам | «продолжение: контекст накоплен, передавать его дорого» |
| 11 | иначе | сам | «уровень sonnet не выше модели сессии (opus)» / «хватит sonnet; модель сессии хуку неизвестна» |

Если делегирование ведёт к haiku/fable или effort low/max без согласия пользователя, действие — **спросить** («fable и effort max: только с согласия пользователя»): один `AskUserQuestion`, «да» → `Agent(…)` из заметки, «нет» → безопасная замена (haiku → sonnet, fable → opus, low → medium, max → xhigh) или «сам», если модель сессии уже не ниже замены. Делать haiku/low-задачу самому подтверждения не требует.

## Признаки

| Признак | Откуда | Примеры |
|---|---|---|
| Явная просьба о субагенте / сделать самому | текст запроса без цитат и пересказа | «используй субагента», «через агента», «делегируй», "use a subagent"; «сделай сам», «без субагента», «не делегируй», "do it yourself" |
| Общее устройство или сессия | текст + проект | «эмулятор», «adb», «на телефоне», «в моём браузере», «я уже вошёл», CDP; профиль `.profile/` с `DevToolsActivePort`; открытый пункт `TASKS.md` про прогон/браузер |
| Долгое ожидание | текст | «подожди», «дождись», «soak», «всю ночь», «на 60 минут», «в течение часа», «каждые 10 минут», "wait for" (от 5 минут) |
| Небольшая задача или диалог | TypeSafe + текст | сложность и рассуждение не выше 1/3 (или уверенное «только чтение» / «механика») без слов риска; короткий вопрос «что такое…?» |
| Большая задача | TypeSafe + текст | сложность или объём от 0.85; от 5 файлов или 6 пунктов; «весь проект» |
| Стоимость передачи контекста | текст + сессия | продолжение, «как мы обсуждали», «найденные ранее дефекты»; длинная сессия (стенограмма от 3 МБ) или от 3 оценённых запросов сессии |
| Параллельные части | текст | «параллельно», «для каждого», «независимые части» + пункты списка |
| Модель сессии | стенограмма → `ANTHROPIC_MODEL` → `settings.json` | `TYPESAFE_TRIAGE_SESSION_MODEL=<модель>` — задать самому, `=unknown` — не определять |

## Реже: когда заметки нет

Короткое продолжение (`«продолжай …»`, `«и ещё …»`, `"continue"`, до 300 знаков) **молчит**, если совпали действие, модель, effort и не появилось новых пунктов (долгое ожидание, общее состояние, параллельность), и нет подтверждения, уточняющего вопроса, предупреждения TypeSafe и сбоя. В журнал — запись `quiet` без текста запроса (время, хеш, длина, хеш сессии, решение); она продолжает историю сессии. Строка «TypeSafe-триаж пропущен: …» остаётся для пропусков и сбоев.

## Параметр effort у Agent

Хук схему инструментов не видит. Источники: `TYPESAFE_TRIAGE_AGENT_EFFORT=yes|no` → `--set-agent-effort yes|no` (config.json скилла) → стенограмма (успешный вызов `Agent` с полем `effort`). Известно «есть» — пункт «effort=… — параметром Agent: он есть, а правило CLAUDE.md/скилла — явное требование его передать», без `--run`. «Нет» — фраза глубины в промпт и `--run` для критичного. Неизвестно — условная формулировка и просьба один раз записать ответ.
