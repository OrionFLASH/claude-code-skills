# Как определяется уровень модели

Источник правды — константы вверху `scripts/typesafe_triage.py` и `scripts/triage_heuristics.py`. Здесь — смысл и порядок.

## 1. Вопросы к TypeSafe (один запрос)

Состояние: `{"task": <дайджест текста>}`. Вопросы на английском (основной язык Jev; русский понимается хуже — это компенсируется осторожными правилами). По документации TypeSafe: одна мысль на вопрос, уровни шкалы описывают **ситуации** (с примерами из разных областей), редкий крайний случай — отдельный верхний уровень. Все вопросы идут одним запросом параллельно, лишние почти ничего не стоят.

| Id | Тип | Что спрашивает | Уровни / смысл «да» |
|----|-----|----------------|---------------------|
| `complexity` | Score, 4 ур. | сколько работы | быстрый ответ/крошечная правка → небольшая самостоятельная работа → существенная работа из согласованных частей → большой/открытый проект с проектными решениями |
| `reasoning` | Score, 4 ур. | сколько аккуратного мышления | механика → рутина по образцу → аккуратно (варианты, причина, крайние случаи) → глубоко (новая/тонкая задача, где ошибка выглядит правдоподобно) |
| `ambiguity` | Score, 3 ур. | насколько неясно, что сделать | точно → пробелы с разумными умолчаниями → открытая задача, сначала исследовать/уточнить |
| `risk` | Score, 4 ур. | цена незаметной ошибки | ничего не меняется → легко проверить и откатить → ошибка может пройти незаметно / дорого откатить → критично или необратимо (прод, безопасность, деньги, юридическое/медицинское, миграция без отката) |
| `breadth` | Score, 4 ур. | сколько материала держать в голове | только сообщение → один файл/документ → несколько источников вместе → весь код, большой набор данных, много источников |
| `read_only` | Noul | только объяснить/найти/перечислить, ничего не меняя | |
| `mechanical` | Noul | чисто механическое преобразование без решений | |
| `needs_investigation` | Noul | причина проблемы неизвестна, нужна диагностика | |
| `silent_errors` | Noul | создаёт/меняет правила, формулы, расчёты над данными, где ошибка тихо даст неверный результат | |
| `irreversible` | Noul | действие трудно или невозможно отменить | |
| `novel_design` | Noul | нужно придумать новое (дизайн, стратегия, аргумент, творческий текст) | |
| `conversational` | Noul | это просто реплика, а не задача | |
| `domain` | Choice | тип работы: software, writing, analysis, data, research, planning, operations, conversation, other | только для заметки и журнала |

Из ответа берутся: значение шкалы, нормированное на верхний уровень (0..1); её `confidence`; **вероятность верхней половины** шкалы (сумма `probabilities` уровней выше середины) — она показывает «уверенно просто», даже когда модель колеблется между двумя нижними уровнями. Для Noul уверенность — `|2p − 1|`, как советует документация.

## 2. Локальные сигналы по тексту (`triage_heuristics.py`, без сети)

Длина прозы (без кода в ```` ``` ```` и длинных вставок), пункты списков, перечисления через запятые и двоеточия, слова-связки шагов («затем», «этап», «then»…), пути и имена файлов, наличие кода и логов, «глубокие» слова («почему», «спроектируй», «разберись», «стратегия», «проанализируй», «обратная совместимость»…), «лёгкие» слова («переименуй», «покажи», «перечисли», «только», «ничего не меняй»…), группы слов критичности: `production`, `irreversible`, `security`, `money`, `legal_medical`, `data_loss`. Из них — оценки тех же пяти осей 0..1 и собственная нагрузка текста. Посмотреть: `--signals "текст"`.

Отдельно `is_chatter`: короткая (≤ 160 знаков) реплика, начинающаяся со «спасибо / ок / да / давай / продолжай / thanks…» и без глагола-поручения, — не задача и в TypeSafe не уходит.

## 3. Объединение (детерминированно, `decide`)

1. Нагрузка TypeSafe = Σ вес × значение: `complexity 0.30`, `reasoning 0.25`, `ambiguity 0.15`, `risk 0.20`, `breadth 0.10`.
2. Эвристика **только поднимает**: если нагрузка текста выше, добавляется `HEUR_RAISE = 0.4` разрыва. Вниз текст не тянет.
3. Базовый уровень: < `LOAD_SONNET 0.25` → haiku; < `LOAD_OPUS 0.60` → sonnet; иначе opus.
4. **Ворота haiku** (все условия): `read_only` или `mechanical` ≥ 0.8; `risk` ≤ 0.34; вероятность «открытой задачи» ≤ 0.3; уверенность осей `complexity/reasoning/risk` ≥ 0.7 **или** их верхняя половина ≤ 0.15; в тексте нет слов критичности (кроме чисто читающих задач) и нагрузка текста < 0.40. Иначе — sonnet.
5. Защита: `silent_errors`/`needs_investigation`/`irreversible`/`novel_design` ≥ 0.5 → не ниже sonnet. Высокая цена ошибки (`silent_errors` или `irreversible` ≥ 0.6, или `risk` ≥ 0.9) при `complexity` ≥ 0.5 и не только чтении → opus. Новизна ≥ 0.6 при `complexity` ≥ 0.6 → opus.
6. Низкая уверенность (< 0.5) → один шаг вверх, только если нагрузка не дальше `ESC_MARGIN 0.15` от следующего порога, и не выше opus.
7. **fable**: уже opus, нагрузка ≥ `LOAD_FABLE 0.84`, уверенность ≥ 0.7, признак критичности (`risk` ≥ 0.9, или `irreversible` ≥ 0.8, или `complexity` и `reasoning` ≥ 0.9) и текст согласен (есть слова критичности или нагрузка текста ≥ 0.45).
8. Реплика: `conversational` ≥ 0.8 при `complexity` ≤ 0.2 и уровне не выше sonnet → заметку не добавлять.

## 4. Запасной вариант без TypeSafe (`decide_heuristic`)

Нет ключа, сеть, тайм-аут, пауза защиты, слишком большой вход → только по тексту: нагрузка текста ≥ `H_LOAD_OPUS 0.36` или ≥ 2 групп слов критичности при заметном объёме → opus, иначе sonnet. Никогда haiku и fable. В результате `source: "heuristic"`, `confidence: "низкая"`, в заметке — «только эвристика, уверенность низкая».

## 5. Подтверждение haiku / fable

`CONFIRM_TIERS = {"haiku": "sonnet", "fable": "opus"}`. В результате триажа: `confirm: true` и `fallback` — безопасная замена. Заметка хука требует `AskUserQuestion` перед запуском агента; `--run` без `--confirmed` понижает рекомендацию до замены, а явный `--tier haiku|fable` без `--confirmed` отклоняет (код 2); `build_agent_cmd` без `confirmed=True` бросает `ValueError`.

## 6. Подбор порогов

`--selftest` гоняет `scripts/triage_cases.json` через TypeSafe, `--selftest --heuristic` — офлайн. Метки: `ok`, `over` (выше ожидаемого — дорого, но безопасно), `UNDER` (ниже — опасно, должно быть 0), `NOSIG` (TypeSafe не ответил). Ожидание `skip` — реплика, заметки быть не должно. При разборе полезно смотреть сырые ответы: `python3 typesafe_triage.py "текст"` печатает метрики (значение и уверенность каждой оси) и сигналы.

Известные слабые места Jev: арифметика, даты, длинный шумный вход, русский хуже английского; уверенность шкал из четырёх уровней на простых задачах часто 0.5–0.7 (модель колеблется между «механикой» и «рутиной») — поэтому для haiku есть второй критерий через верхнюю половину шкалы.
