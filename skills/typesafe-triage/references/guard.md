# Сбои, баланс и расходы (`scripts/typesafe_guard.py`)

Баланс TypeSafe через API прочитать **нельзя** (эндпоинта нет, проверено), а документация не описывает ответ при нехватке средств. Поэтому защита опирается на то, что надёжно. Модуль общий: его импортирует и `analyze_issues.py` скилла `github-issue-structuring` (публичное API: `status`, `classify_http`, `record_failure`, `record_success`, `resume`, `pause_manual`, `set_budget`, `summary`, `message`).

- **Нет средств / лимит / оплата** (HTTP 402; тело ответа со словами credit, balance, billing, payment, quota, insufficient…; 429 с признаками квоты), **ключ не принят** (401), **доступ запрещён** (403) → **жёсткая пауза**: запросы к TypeSafe прекращаются полностью, автоматических «проб» нет (чтобы не уйти в минус). Снять: исправить ситуацию на https://console.typesafe.ai и выполнить `--resume`. Пауза из-за ключа снимается сама, как только `TYPESAFE_API_KEY` изменится.
- **Сбои сервиса** (5xx, 529, лимит скорости 429, тайм-аут, нет сети) → временная пауза 5 мин → 10 → 20 … до 1 ч (или `Retry-After`, если он больше); после неё первый же запрос проверяет, ожил ли сервис. Пользователя предупреждают только при устойчивом сбое (3-й и 10-й подряд) и сообщают, когда сервис ожил.
- **Локальный потолок расходов** — предохранитель, а не баланс: входные токены из ответов API × публичная цена $0.042 за млн, по умолчанию **$2 в месяц** (`--set-budget USD`, 0 = без потолка); предупреждение на 80 %, на 100 % — пауза до следующего месяца или до `--resume` после увеличения потолка. Считает только запросы с этой машины. Один запрос триажа — порядка 1–2 тыс. входных токенов (≈ $0.00005–0.0001).
- **Пока TypeSafe на паузе**, уровень выбирается локальной эвристикой (sonnet/opus, «уверенность низкая»): работа не останавливается и совет не пропадает.
- **Как узнаёт пользователь:** хук добавляет `systemMessage` (показывается в окне напрямую) и строку «ВАЖНО (TypeSafe): … сообщи пользователю …» в контекст модели. Напоминание о жёсткой паузе — не чаще раза в 6 часов. Хук **никогда не блокирует** запрос и не падает: при любой проблеме Claude Code работает как обычно.
- Состояние и настройки: `~/.claude/typesafe-triage/` (`state.json`, `config.json`, `log.jsonl`; права 0600). Каталог можно сменить переменной `TYPESAFE_TRIAGE_HOME` (для тестов и экспериментов).
- Сломался хук или нет ответа → `--check`. Типичная причина — у сборки Python нет корневых сертификатов; скрипт сам берёт системный пакет CA (проверка сертификата не отключается).
