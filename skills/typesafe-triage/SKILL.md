# TypeSafe-триаж задач (глобальный, универсальный)

Короткая оценка **каждого** запроса пользователя — не только про код: документы, письма, анализ, данные, исследование, планирование, ревью, ops. TypeSafe (модель Jev: типизированные ответы и вероятности, ~100 мс, доли цента) отвечает на узкие вопросы-шкалы, локальные эвристики считают сигналы по тексту, а **код** (не модель) детерминированно выводит уровень: `haiku` < `sonnet` < `opus` < `fable`. Работает во всех репозиториях и сессиях.

## Что происходит автоматически

Глобальный хук `UserPromptSubmit` (в `~/.claude/settings.json`) вызывает `scripts/typesafe_triage.py --hook` и добавляет к запросу заметку «TypeSafe-триаж: уровень …» с коротким указанием, что делать.

- **Пропускаются** (в TypeSafe не уходят, заметки нет): реплики короче 40 символов, подтверждения и благодарности без поручения («спасибо, давай дальше», «ок, продолжай»), команды `/…`, служебные сообщения среды (`<task-notification>`, отчёты субагентов и т. п.). Если TypeSafe уверенно считает сообщение просто репликой — заметки тоже нет.
- **Всё остальное от 40 символов уходит в TypeSafe** (см. «Приватность»).
- TypeSafe недоступен (нет ключа, сеть, пауза защиты, ошибка) → уровень по **локальной эвристике**: только `sonnet` или `opus`, пометка «только эвристика, уверенность низкая». «Рекомендации нет» больше не бывает.

## Как применять заметку (обязательно, без напоминаний)

Основную сессию Claude Code переключить нельзя (нет механизма; только `/model` руками) — «переключение» делается делегированием.

1. **Делегируй** через `Agent(model=<уровень>)`, если работа содержательная (анализ, проектирование, нетривиальная правка, поиск причины, большой текст) **и** уровень выше твоей модели, **или** задача большая и хорошо изолируется. Промпт агенту — самодостаточный: цель, пути, ограничения проекта (CLAUDE.md), критерии готовности, что вернуть. Результат прочитай и проверь сам.
2. **Делай сам**: диалог, мелочи, уточнения, уровень не выше твоего. Триаж не упоминай.
3. **haiku и fable — только с подтверждения.** Прежде чем запускать агента на них — `AskUserQuestion` «Запустить агента на fable?» (или haiku) с вариантами «Да, fable» / «Нет, opus» (для haiku: «Да, haiku» / «Нет, sonnet»). Нет явного «да» (отказ, нет ответа) → работай на ближайшем безопасном: **haiku → sonnet, fable → opus**. `sonnet` и `opus` — без вопросов. Если haiku-задачу проще сделать самому, не делегируй и не спрашивай.
4. Субагентам ставь уровень **не ниже рекомендованного**, а для содержательных подзадач — **не ниже твоей модели**: оценка относится к запросу целиком.
5. Заметка «**ВАЖНО (TypeSafe)**» → в начале ответа одной-двумя строками передай пользователю её текст (что случилось и какая команда исправит), дальше работай по уровню из заметки.

## Гарантии качества (не ослаблять)

- haiku и fable **никогда** не запускаются автоматически (константа `CONFIRM_TIERS`; в `--run` — только с `--confirmed`).
- **fable** — только при очень высокой нагрузке (≥ 0.84), высокой уверенности TypeSafe (≥ 0.7) и признаке критичности (цена ошибки на верхнем уровне шкалы, уверенная необратимость или предельная сложность и рассуждение), подтверждённом текстом. Низкая уверенность до fable не поднимает.
- **haiku** — только уверенно простое чтение/механика с низким риском; при любых словах риска или заметном объёме в тексте — нет. Без ответа TypeSafe — никогда.
- Вверх — легко, вниз — только при уверенных ответах; низкая уверенность у границы уровня = шаг вверх (один, не выше opus). Эвристика текста только поднимает нагрузку.
- Совет не отменяет проверки: тесты, чтение результата субагента, проверка на данных; при сомнении — уровень выше.

Как именно считается уровень (вопросы, сигналы, веса, пороги) — [references/levels.md](references/levels.md).

## Если ты субагент

Запущен через `Agent` или `--run` — этот скилл **не применять**: не запускать триаж, не делегировать «наверх», не менять уровень. Модель выбрал тот, кто тебя запустил. Если задача слишком сложна для твоего уровня — скажи об этом в отчёте («нужен более сильный исполнитель»), а не запускай другого агента. В агенте `--run` хук молчит сам (`TYPESAFE_TRIAGE_CHILD=1`), вложенный `--run` запрещён.

Совместная работа с SuperPowers и приоритет их Model Selection — [references/superpowers.md](references/superpowers.md).

## Запуск вручную

Скрипты: `~/.claude/skills/typesafe-triage/scripts/` (только стандартная библиотека Python; ключ — `TYPESAFE_API_KEY` в окружении, например в `~/.claude/settings.json` → `env`).

```bash
S=~/.claude/skills/typesafe-triage/scripts
python3 $S/typesafe_triage.py --check                      # диагностика: ключ, сеть, сертификаты (0 — ответ TypeSafe получен)
python3 $S/typesafe_triage.py "текст задачи"               # JSON: уровень, источник, метрики, сигналы, причины
python3 $S/typesafe_triage.py --digest "текст"             # что именно уйдёт в TypeSafe (или текст из stdin)
python3 $S/typesafe_triage.py --signals "текст"            # локальные сигналы эвристики, без сети
python3 $S/typesafe_triage.py --status                     # пауза (если есть), расходы за месяц, потолок
python3 $S/typesafe_triage.py --resume                     # снять паузу после пополнения баланса / исправления ключа
python3 $S/typesafe_triage.py --pause "причина"            # отключить TypeSafe вручную;  --set-budget 5  месячный потолок, USD
python3 $S/typesafe_triage.py --run "текст задачи"         # триаж + отдельный агент `claude -p --model <уровень>`
#   --readonly  только читать/планировать (--permission-mode plan)
#   --edit      разрешить правку файлов в текущем каталоге (acceptEdits); БЕЗ --edit/--readonly агент в режиме -p не получает права
#               на запись и останавливается с просьбой о разрешении (проверено) — для задач с правками указывать --edit
#   --allow "Bash(python3 -m pytest:*)"  доп. разрешённые инструменты (можно несколько раз)
#   --tier haiku|sonnet|opus|fable  вручную; haiku и fable — только вместе с --confirmed, иначе отказ (код 2)
#   --confirmed  пользователь явно подтвердил haiku/fable; без него рекомендация haiku/fable понижается до sonnet/opus
#   --budget USD  потолок расходов агента   --dry-run  показать уровень и команду, ничего не запускать
python3 $S/typesafe_triage.py --selftest                   # эталонные задачи (triage_cases.json) через TypeSafe, нужна сеть
python3 $S/typesafe_triage.py --selftest --heuristic       # те же задачи только по эвристике (офлайн)
python3 -m pytest $S -q -p no:cacheprovider                # все офлайн-тесты (нужен pytest)
```

`--run` запускает **отдельный процесс** без истории диалога: весь контекст — в тексте задачи (через stdin), рабочий каталог — текущий, права вашего `defaultMode` в `-p` не наследуются. `--confirmed` ставить **только** после явного согласия пользователя.

## Сбои, баланс и расходы

Защита `typesafe_guard.py` (её же использует `analyze_issues.py` скилла `github-issue-structuring`): нет средств / ключ не принят / доступ запрещён → **жёсткая пауза** до `--resume` без автоматических проб; сбои сервиса → временная пауза 5 мин → … → 1 ч; локальный потолок расходов (по умолчанию $2 в месяц). Пользователь видит `systemMessage`, а модель получает «ВАЖНО (TypeSafe)». Пока пауза — уровень по эвристике. Хук **никогда не блокирует** запрос и не падает: любая неожиданность = молчание. Подробности — [references/guard.md](references/guard.md).

## Приватность и выключатели

- **В TypeSafe уходит каждый запрос от 40 символов, кроме пропускаемых** (реплики, команды, служебные сообщения) — теперь любой тематики, не только код. Уходит не сам текст, а **дайджест до 4500 знаков**: большие вставки (код, логи) сжимаются до начала и конца, строки, похожие на ключи, токены и пароли, заменяются на «[скрыто]». Файлы проекта и данные не отправляются. Посмотреть: `--digest "текст"`.
- Где это недопустимо (рабочие/закрытые проекты, личная переписка): пустой файл **`.typesafe-triage-off`** в каталоге проекта (или выше) либо **`TYPESAFE_TRIAGE=off`** — тогда хук полностью молчит и ничего не отправляет. `--pause` отключает только TypeSafe (останется локальная эвристика).
- Журнал решений: `~/.claude/typesafe-triage/log.jsonl` (первые 200 символов запроса с маскировкой секретов, метрики и сигналы; права 0600, только локально; реплики не пишутся).

Подробно о дайджесте, лимитах размера и журнале — [references/privacy.md](references/privacy.md).

## Как подстраивать

Все пороги и веса — константы вверху `typesafe_triage.py` (`WEIGHTS`, `LOAD_*`, `CONF_*`, `HAIKU_*`, `FABLE_*`, `H_*`), словари сигналов — вверху `triage_heuristics.py`. Любое изменение — через `--selftest` (и `--selftest --heuristic`) на `triage_cases.json`: добавляй реальные задачи любых тематик с ожидаемым уровнем (`haiku`/`sonnet`/`opus`/`fable`/`skip`); «ниже ожидаемого» должно быть 0. Вопросы к TypeSafe — `SCORES`, `FLAGS`, `CHOICES`: одна мысль на вопрос, уровни шкалы — конкретные ситуации с примерами. Перед правкой вопросов перечитать живую документацию https://docs.typesafe.ai (Choice / Noul / Score, confidence). Порядок и обоснование — [references/levels.md](references/levels.md).
