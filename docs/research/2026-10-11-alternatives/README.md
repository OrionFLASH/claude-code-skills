# Можно ли заменить свои скилы сторонними (исследование 2026-10-11)

Откройте `index.html` двойным кликом (офлайн, без сервера). В отчёте: итог по четырём скилам и режиму идеи, матрицы покрытия возможностей (клик по ячейке — примечание и ссылки-доказательства), пузырьковые диаграммы «покрытие × популярность», радары, таблицы кандидатов с фильтрами, раздел про ECC и другие коллекции, план действий и 300+ источников.

- `data/*.json` — исходные данные по каждому скилу и коллекциям (кандидаты, оценки 0–3 с доказательствами, вердикты);
- `data/overview.json` — общий вывод и план действий;
- `BRIEF-common.md` — бриф исследования (матрицы возможностей, правила оценки);
- `build_report.py` — пересборка сайта: `python3 build_report.py`; `template/` — исходники страницы.

Вердикты: ни один из скилов не заменяется целиком; QA сайтов и выбор модели — частично (ядро можно взять готовым), QA Android — только внешний бэкенд управления устройством, стратегия — оставить своим, концепция — частично заменима.
