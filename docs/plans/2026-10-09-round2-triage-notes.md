## Найдено по дороге

- **Разный уровень на Python 3.9 и 3.14 при одних и тех же ответах.** `sum()` для float в Python 3.12+ компенсированный, и нагрузка ровно на пороге (все оси 0.6 → 0.6 = `LOAD_OPUS`) давала sonnet на 3.9 и opus на 3.14. Исправлено округлением нагрузки и глубины до 9 знаков; офлайн-`--selftest` без изменений (train 65/65, holdout 17/17 по модели, «ниже ожидаемого» 0).
- **INSTALL сам создавал «призрак»:** советовал переименовать старую копию в `~/.claude/skills/typesafe-triage.bak-…`, а такую папку Claude Code читает как второй скилл `typesafe-triage`. Теперь резервные копии — в `~/.claude/backups/`; `--check` такие копии находит. Скрытые папки (`.trash`) Claude Code не читает — проверено: копия в `~/.claude/skills/.trash/` в списке скиллов этой сессии не видна.
- **«продолжай, распиши …» считалось репликой без поручения** (2.2: «распиши», «допиши», «доделай» не входили в слова-поручения) и не доходило до наследования. Исправлено.
- **Продолжение после «спросить» (согласие на агента)** получало «сам — небольшая задача»; теперь наследует делегирование. Найдено живым прогоном.
- В кэше плагинов рядом с 2.2.0 лежит папка 2.1.3; `installed_plugins.json` указывает на 2.2.0 — вреда нет, `--check` смотрит на установленную версию.
- Стенограмма основной сессии этого оркестратора показывает модель `claude-sonnet-5-5`, а субагенты работают на opus: «уровень выше моей модели» действительно надо сравнивать с моделью основной сессии, а не угадывать. `--check`, запущенный из субагента, видит стенограмму основной сессии (по `CLAUDE_CODE_SESSION_ID`) — так и задумано.
