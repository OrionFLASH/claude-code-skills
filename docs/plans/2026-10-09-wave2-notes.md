## Отложено

| Пункт | Что не сделано | Почему |
|-------|----------------|--------|
| T-1 | Источники «последний план ассистента» и «последнее сообщение ассистента» для строки «активная задача» | Для этого хук должен читать стенограмму сессии (`transcript_path`) и отправлять в TypeSafe текст ответов ассистента. Это расширяет то, что уходит наружу (до 2.2 уходил только текст запроса пользователя). Формат стенограммы внутренний и не документирован. Случаи из отзыва («продолжай тесты», «и ещё добавь…») закрывают две вещи: наследование оценки предыдущего запроса из локального журнала и строка из `TASKS.md`. Вернуться, если наследования окажется мало: читать только последний блок текста ассистента, не больше 200 знаков, по отдельному согласию (`TYPESAFE_TRIAGE_CONTEXT=assistant`). |
| T-4 (Windows) | Защищённая форма ручного хука (`if [ -f … ]`) для PowerShell 5.1 без Git Bash | На Windows хуки выполняются в Git Bash, и там форма из INSTALL.md работает. Для PowerShell 5.1 нужен отдельный синтаксис, а проверить его здесь негде. Хук плагина (`${CLAUDE_PLUGIN_ROOT}`) этой проблемы не имеет. |
| — | Пункт 4.1 отзыва: в вопросах права и финансов с высокой ценой ошибки обязательна вторая проверка нормы | Этого нет в списке T-1…T-6 плана волны 2. Для site-qa-audit это «Юридическое» в волне 1. Для триажа можно добавить строку заметки при словах `legal`/`finance` из `CRITICAL_GROUPS`, но это отдельное решение о тексте заметки. |

- `~/.claude/skills/github-issue-structuring/scripts/analyze_issues.py` импортирует `typesafe_guard` из `~/.claude/skills/typesafe-triage/scripts`, а в его `SKILL.md` есть команда `--check` по тому же пути. После перехода typesafe-triage на плагин (папка `~/.claude/skills/typesafe-triage` удалена 2026-10-09 в 00:28:44) импорт там не находит модуль. Нужно перевести этот скилл на поиск пути (кэш плагина / `--where`) или вендорить `typesafe_guard.py`.
- В `~/.claude/skills/.trash/typesafe-triage-copy-20261008/` осталась старая копия скилла. Удалять или нет, решает пользователь.

## Не проверено вживую

- Живой хук в Claude Code (плагин 2.2.0) не проверялся: хук подключается при старте сессии или после `/reload-plugins`, а в этой работе сессию не перезапускали. Поведение проверено офлайн-тестами, в том числе на настоящих процессах и на поддельном сервере.
- Живой TypeSafe проверен одним ручным прогоном `--hook` с изолированным состоянием: задачу «Проверь сайт на ошибки в мобильной версии и заведи issues со скриншотами» он отнёс к новому типу `qa` с уверенностью 1.0. Полный живой `--selftest` (82 кейса) не запускался: вопросы, влияющие на модель и effort, не менялись, а `domain` на уровень не влияет.
