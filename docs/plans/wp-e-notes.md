## CHANGELOG.md — строки для [1.5.0]
### Добавлено
- **Слой интерактивности в генераторе страницы (FB-035)**: у каждого графика и схемы — видимая кнопка «🔍 Увеличить» (на телефоне над картинкой,
  ≥ 44×36 px), курсор zoom-in на фоне, плашка при наведении, строка «Графики и схемы кликабельны…» вверху и в разделах; просмотр на весь экран с
  **живым SVG** (не картинкой): «−/+/Сброс/Панель/✕», колесо, щипок трекпада (Safari `gesture*`) и пальцами, двойное касание, перетаскивание,
  клавиши; каждый элемент наводится и нажимается, панель «Что это / Что значит / Что делать / Метрики / Связанные предложения / Где на странице»
  (схемы — «Как сейчас / Что сделать / Как измерять»), список всех элементов для мелких и перекрытых, P-id — карточка поверх просмотра, Esc по
  слоям, фокус не выходит из окна; на телефоне — нижний лист. Мгновенная подсказка «название + что это» при наведении и фокусе на странице.
  Источник — `templates/site/ps-interact.js|ps-layer.css`; `postprocess_interactive.py`/`postbuild_enhance.py` больше не нужны.
- **Сквозной поиск по странице** (`templates/site/ps-search.js`): «/», Ctrl/Cmd+K, `#q=`; разделы, реестр, конкуренты, блоки схем, план,
  Kanban, пояснения графиков, глоссарий и прочие `research/**/*.md`; начало слова, формы слова без ложных совпадений («цена» ≠ «ценность»),
  фраза, «любое из слов», «внутри слова», е/ё; фильтры по виду, подсветка в выдаче и на странице после перехода.
- **Кликабельные сущности текста** (`templates/site/ps-ents.js`): «раздел N», G-id, M-ключи макетов, названия конкурентов, ID строк таблиц
  (H1, E03, R12…), термины глоссария (подсказка, окно «где упоминается»); раздел «Глоссарий» из `research/glossary.md` (`build_appendix.py`).
- **Просмотр макетов**: «Открыть интерактивный макет», связанные P-id, вторая тема снимка (`themes` / `png_dark` в `mockups-index.json`),
  зоны подсказок элементов (`mockups/hotspots.json` или атрибуты `data-hs-*` HTML); ссылки на `mockups/gallery.html` и `prototype/index.html`.
- **Хуки расширения во всех режимах**: `build/extra.css|js` и `build/extra/*.css|js` встраиваются и в `--single/--lite` (свой хеш CSP);
  `window.PS` (`data`, `router`, окна, `on/emit`, `replace`) — расширение может взять компонент на себя, smoke пропускает его проверки с пояснением.
- **Гант на весь горизонт**: шкала плана по `horizon_months`, видение до конца года последней задачи («7–12», «год 2» вместо «мес. 7–18»),
  пробелы плана (месяцы без задач) заштрихованы и названы на странице и на графике `charts.py` (`gap-<с>-<по>`), предупреждение сборщика.
- **smoke: видимость и интерактивность (FB-036)**: `viewer-structure`, `viewer-hover` (настоящее наведение без force), `viewer-open`,
  `viewer-elements` (≤ 40 элементов на график, перекрытые — через список), `viewer-mobile`, `viewer-print`, `search`, `entities`, `mockup-viewer`;
  в WebKit/Firefox — по каждому графику и схеме; на странице без слоя проверки падают со списком провалов по каждому графику.

### Исправлено
- **Стабильная высота ленивых заглушек (FB-037)**: `aspect-ratio` из viewBox и высота на телефоне у мест под графики, размеры у `<img>` —
  переход по меню на телефоне больше не «уезжает».
- **Доступность схем (FB-038)**: `role="group"` вместо `img`, `aria-labelledby` только на существующие id, `<title>` у каждого блока из
  `flows.json → what`, `aria-label` блоков; `check_flow.mjs` падает на описанном блоке без `<title>` (`--strict-titles` — на любом).
- **Мелкие WARN сайта (FB-039)**: карточка реестра на ≤ 900 px свёрнута (открыта «Суть», остальное — «Подробнее» с числом пунктов); пустая
  колонка таблицы текста не выводится, колонке-«выбросу» — ширины `<colgroup>`; Firefox — «skip» с причиной (и из `build/env.json`).
- **smoke без жёстких фраз** (SM 6.4): поиск конкурента — по названию из данных; блок схемы — настоящим кликом; поиск в реестре, конкурентах
  и фильтрах таблиц понимает несколько слов и «фразы».
