# Разбор ECC (affaan-m/ECC, everything-claude-code) — 2026-10-13

Откройте `index.html` двойным кликом (офлайн, без сервера). Что внутри:
- итог и главные находки; состав репозитория (71 агент, 311 скилов, 97 команд, правила, MCP, прочее) — таблицы с поиском и фильтрами;
- схема взаимодействия: архитектура ECC и «исследователь цепочек» команда → агент → скил → хук (связи извлечены из исходников, у каждой — степень уверенности);
- установка: способы, что пишется на машину, профили, модули, CLI, переменные окружения, удаление;
- хуки: что запускается само (карта по событиям, риск, сеть, вложенный claude), что вручную;
- безопасность и утечки данных: находки с доказательствами и ссылками на строки кода, карта категорий × серьёзность, схема потоков данных, сетевые адреса, журналы, цепочка поставки;
- как использовать в разработке: сценарии, шпаргалка всех команд, память и «инстинкты», минимальная безопасная установка для вас, совместимость с вашей настройкой;
- ECC и ваша установка (2026-10-18): вердикт, сценарии A–F, пересечения со Superpowers/TypeSafe/своими скилами, конфликты, замеры задержки хуков и бюджет контекста, куда уходят данные, что отключить, пошаговые инструкции и откат, ваши кейсы (`data/setup.json`, `mechanics.json`, `integration.json`, бриф `BRIEF-integration.md`);
- что известно снаружи: GitHub и npm, issues, отзывы, проверка заявлений README.

Данные: `data/*.json` (inventory, runtime, security, graph, usage, web, overview, setup, mechanics, integration); скрипты построения графа и инвентаризации лежат рядом (`data/build_graph.py`, `data/inventory-build/`). Пересборка: `python3 build_report.py`. Бриф исследования: `BRIEF-ecc.md`.
