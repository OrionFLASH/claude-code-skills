## Проблема
- Требования разбросаны по четырём INSTALL.md и отличаются по скилам: Python 3.8+ у site-qa-audit (`skills/site-qa-audit/INSTALL.md:168`), но 3.9+ в его же SKILL.md (`skills/site-qa-audit/SKILL.md:183`); 3.9+ у android-qa-audit (`skills/android-qa-audit/INSTALL.md:154`); 3.10+ у product-strategy (`skills/product-strategy/INSTALL.md:132`, проверка `skills/product-strategy/scripts/check_env.py:165`) [факт: код, 2026-10-10].
- Тяжёлые требования видны только внутри INSTALL: для android-qa-audit — JDK 17+, Android SDK, эмулятор, ≈3 ГБ памяти на эмулятор, 16 ГБ ОЗУ для двух потоков, 15+ ГБ диска (`skills/android-qa-audit/INSTALL.md:156-171`); для site-qa-audit — Node, Playwright MCP, Chromium (`skills/site-qa-audit/INSTALL.md:167-172`) [факт].
- Стоимость прогона нигде не названа: в depth-matrix и parallelism нет слов «стоимость/токен» [факт: P001.current_feature, grep 2026-10-10]; единственные числа — цена TypeSafe $0,042 за 1 млн входных токенов (`skills/typesafe-triage/scripts/typesafe_guard.py:27`) и потолок $2 в месяц по умолчанию (`skills/typesafe-triage/scripts/typesafe_guard.py:44`).
- Лицензия описана подробно, но внизу (`README.md:79-89`); что NC значит для работы на компанию — в таблице «Нельзя без разрешения автора» (`README.md:85`) [факт].
- Внешний сервис в typesafe-triage: каждый запрос от 40 символов уходит в TypeSafe (`skills/typesafe-triage/README.md:87`), но без ключа скил работает на локальных сигналах (`skills/typesafe-triage/README.md:29`, `:37`) — оба факта должны быть рядом [факт; `research/gap-audit.md`, «Бесплатно и платно»].

## Цель и метрики успеха
- **Основная:** 3 из 3 читателей по блоку правильно отвечают «смогу ли я запустить скил X на своей машине и сколько это займёт» [оценка; cheap_test реестра].
- **Исход:** доля отказов после установки ↓ на 5–15 % [ДОПУЩЕНИЕ: из реестра; прокси — Issues вида «не запускается / не хватает X» на 100 клонов, по снимкам P043 и Issues].
- **Защитные:** 0 расхождений блока с INSTALL.md и `LICENSE` (проверка перед слиянием); 0 юридических обещаний сверх лицензии; все числа стоимости помечены «оценка» с датой и способом замера.

## Решение
Компактный блок из двух частей в верхнем экране README (место — пункт 4 в спецификации P029):

**Часть 1. Таблица «скил → кому → что потребуется → первый прогон»** (3–4 колонки, по строке на скил):
| Скил | Кому | Что потребуется | Первый прогон [оценка] |
|---|---|---|---|
| typesafe-triage | всем пользователям Claude Code | Python 3; ключ TypeSafe — по желанию (без него — локальные сигналы); с ключом текст запросов от 40 символов уходит в TypeSafe | минуты; расход TypeSafe — доли цента в день [оценка: формула ниже] |
| product-strategy | основателям, продактам, соло-разработчикам | Python 3.10+, git; Node 18+ и gh — по желанию | демо — минуты, без токенов; настоящий прогон — <замер> |
| site-qa-audit | QA, фронтенд-разработчикам | Node 18+, Python 3.9+, Playwright MCP, Chromium; `npm install` после каждого обновления | smoke — <замер> мин и <замер> токенов |
| android-qa-audit | QA мобильных приложений | JDK 17+, Android SDK и эмулятор, от 16 ГБ ОЗУ на 2 потока, 15+ ГБ диска | smoke — <замер> |

**Часть 2. Три строки под таблицей:**
- Лицензия: PolyForm Noncommercial — бесплатно для личных, учебных, исследовательских и некоммерческих целей; для работы на компанию и в платных продуктах нужна коммерческая лицензия от автора (ссылка на раздел «Лицензия»). Без формулировок «можно в компании, если…».
- Чего скилы не делают: не пентест, только пассивная безопасность (`skills/android-qa-audit/README.md:159`); причина дефекта — гипотеза, код не анализируется (`skills/android-qa-audit/README.md:148`); отчёты и вопросы — на русском (до P053).
- Где данные: результаты и журналы — локально, вне папки скила (`README.md:48`); внешние сервисы — только TypeSafe (по ключу) и GitHub (по вашему согласию на публикацию).

**Как получить числа «первого прогона»** — из собственных прогонов, с меткой «оценка» и датой:
- site-qa-audit: тот же dry-run smoke на todomvc, что для P030 и P032 (`skills/site-qa-audit/tests/dry-run-todomvc.md:7`): время от запроса до `report.md` и расход по `/cost` в конце сессии [ДОПУЩЕНИЕ: `/cost` показывает расход сессии на тарифе API; на подписке — только время].
- product-strategy: время демо (`skills/product-strategy/INSTALL.md:162`) и токены настоящего прогона из `REPORT.md` (там есть раздел о токенах, `skills/product-strategy/README.md:11`).
- android-qa-audit: время smoke на одном эмуляторе из журнала прогона владельца.
- typesafe-triage: формула `запросов в день × токенов на запрос × $0,042 / 1 млн` (`skills/typesafe-triage/scripts/typesafe_guard.py:27`); дайджест до 4500 знаков (`skills/typesafe-triage/README.md:87`) ≈ 1500–2000 токенов [ДОПУЩЕНИЕ: 2,3–3 знака на токен для смешанного RU/EN текста] → ≈ $0,00008 на запрос, 100 запросов в день ≈ $0,25 в месяц, потолок $2 по умолчанию [оценка].

**Не входит:** точная формула и лимит бюджета прогона (P001); решение по лицензии (P042) — блок описывает действующую; английская версия блока (P069 переводит верх README целиком); юридические гарантии.

## Требования
**Функциональные**
- F1. Таблица ≤ 4 колонок и ≤ 4 строк; каждая ячейка ≤ 120 знаков; подробности — ссылками на INSTALL.md скилов.
- F2. Минимальная версия Python по каждому скилу — по коду проверки окружения, а не по тексту: при расхождении (site-qa-audit: 3.8+ в INSTALL против 3.9+ в SKILL.md) в блок идёт большее значение, а расхождение в документах скила исправляется отдельным PATCH скила.
- F3. Все числа стоимости и времени — с меткой «оценка», датой замера, глубиной (smoke) и машиной [ДОПУЩЕНИЕ: MacBook владельца].
- F4. Формулировки лицензии — только из `README.md:83-89` и `LICENSE:33-39`; без «можно», которых там нет.
- F5. Блок не дублирует карточки P029: карточка — «что даёт», блок — «что нужно и чего стоит».

**Нефункциональные**
- Доступность: таблица с заголовками колонок; без смысла, переданного только цветом или эмодзи.
- i18n: RU; EN-версия — в README.en.md (P069) с теми же числами.
- Актуальность: при изменении требований в INSTALL.md скила (новая MINOR) — сверка блока; кандидат на автоматическую проверку в validate после P059 (не в этом объёме).
