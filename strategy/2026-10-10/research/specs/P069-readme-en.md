# P069. Англоязычная витрина: README.en.md с тем же верхом, что у README-витрины
Приоритет: P0 · Горизонт: now · Предпосылки: P029, P030 · Связанные: P054, P053, P052, P018, P019, P024, P025, P050, P028 · Макет: не предусмотрен (дизайн выключен выбором, у продукта нет UI)

Обоснование — P069 в реестре, раздел 10 стратегии; связь с англоязычными каналами — конфликт К1 в `research/gap-audit.md`. Здесь — только как сделать.

## Проблема
- README целиком на русском (`README.md:1-117`), английской версии нет [факт: ls, 2026-10-10]; описания плагинов в `marketplace.json` тоже на русском (`.claude-plugin/marketplace.json:12`, `:35`, `:60`, `:78`) — это P054.
- Каналы привлечения в топе англоязычные (claude-plugins-official, awesome-claude-code, Show HN, Product Hunt) [факт: data/communities.json, language en].
- Скилы спрашивают и пишут отчёты по-русски при любом `language`: язык только записывается в конфиг (`skills/site-qa-audit/scripts/intake.py:230-231`), отчёт строится с русскими заголовками (`skills/site-qa-audit/scripts/build_report.py:233` и соседние строки) [факт: код; data/fact-check.json]. При этом примеры вызова обещают «English report» (`skills/site-qa-audit/README.md:73`, `skills/android-qa-audit/README.md:62`) — англоязычный читатель получит не то, что ждёт.
- Владелец закрепил русский язык документации скилов (SKILL.md, INSTALL.md, README скилов) [факт: run-config.json; `CONVENTIONS.md:50-51`].

## Цель и метрики успеха
- **Основная:** 2 из 2 англоязычных разработчиков по README.en.md за минуту называют, что делает каждый скил и как его поставить, и знают, что отчёты будут на русском [оценка; cheap_test реестра].
- **Исход:** доля клонов от просмотров README в недели англоязычных подач (P018, P019, P024) ↑ на +1..3 п. п. [ДОПУЩЕНИЕ: из реестра]; ≥ 1 принятая заявка из трёх англоязычных каталогов (P018, P019, P050) [ДОПУЩЕНИЕ].
- **Вспомогательные:** просмотры `…/blob/main/README.en.md` в popular paths (P043) от просмотров корня ≥ 10 % в недели EN-подач [ДОПУЩЕНИЕ]; переходы с англоязычных доменов в referrers (P043).
- **Защитные:** 0 обещаний английских отчётов до P053; README.en.md не старше README.md (предупреждение validate); `tools/validate.sh` без ошибок.

## Решение
1. **Файл `README.en.md`** в корне с тем же верхом, что у README-витрины P029: фраза ценности (EN-вариант одной и той же формулировки, P028), те же медиа из `docs/media/` (P030 — без вшитого текста, подписи в Markdown), установка в три строки (команды одинаковы), блок «Who it's for / What you need / Run cost / License» (перевод P033 с теми же числами), четыре карточки скилов, раздел **Limitations** и ссылка на полный русский README для остального.
2. **Раздел Limitations** — честная языковая пометка: «Skills ask questions and write reports in Russian; English reports are planned» (без даты, пока не начат P053); NC-лицензия; ручной `npm install` у site-qa-audit до P060; не пентест.
3. **Переключатель** — первая строка под заголовком в обоих файлах: `RU · [EN](README.en.md)` и `[RU](README.md) · EN`.
4. **Таблица скилов не дублируется**: `sync` перезаписывает таблицу только в `README.md` (`tools/lib/skillsrepo.py:195-197`) и берёт русские описания из `plugin.json` (`tools/lib/skillsrepo.py:193`). В README.en.md — только карточки, написанные вручную; маркеры `skills-table` туда не ставить, иначе `sync` их не обслужит, а ручная копия разойдётся.
5. **Проверка свежести в validate**: в обоих файлах комментарий `<!-- readme-sync: YYYY-MM-DD -->`; `validate` печатает WARN (не ERROR), если в README.en.md дата старше, чем в README.md, или если файла README.en.md нет, а ссылка на него в README.md есть; плюс WARN, если в README.en.md нет ссылки `](skills/<имя>/)` на какой-либо скил.
6. **Ссылки в заявках и постах** (P018, P019, P024, P025, P050) — на `README.en.md`, а не на корень.

**Не входит:** перевод SKILL.md, INSTALL.md и README скилов (P052, горизонт next); английские отчёты и черновики issues (P053); английские `description` в `plugin.json` и `marketplace.json` (P054); переключение интерфейса GitHub; машинный автоперевод в CI.

## Пользовательские сценарии
1. Как англоязычный разработчик из awesome-claude-code, я хочу понять продукт на английском, чтобы решить, ставить ли.
   - Given ссылка из списка ведёт на `README.en.md`; When читаю первый экран; Then вижу фразу ценности, GIF, установку и блок требований на английском, без русского текста в первом экране (кроме названий из интерфейса в медиа).
2. Как англоязычный пользователь, я хочу заранее знать, на каком языке будет результат, чтобы не разочароваться после прогона.
   - Given раздел Limitations; When читаю его; Then вижу, что вопросы и отчёты скилов — на русском, и что английские отчёты в планах без даты.
3. Как посетитель корня репозитория, я хочу переключиться на английский одним кликом.
   - Given `README.md`; When нажимаю `EN` в первой строке; Then открывается `README.en.md`; обратная ссылка `RU` ведёт назад.
4. Как владелец, я хочу узнать, что английская версия отстала, при обычной проверке перед коммитом.
   - Given README.md с `readme-sync: 2026-11-02`, README.en.md с `readme-sync: 2026-10-20`; When запускаю `tools/validate.sh`; Then вижу WARN «README.en.md старше README.md», код возврата не меняется (0 при отсутствии ошибок).
5. Как ревьюер официального каталога, я хочу найти описание мер безопасности на английском.
   - Given README.en.md; When ищу «Safety»; Then нахожу 3–5 строк о dry-run по умолчанию, запретах `url_guard`/`guard.js`, отсутствии публикаций без согласия и ссылки на русские справочники (`skills/site-qa-audit/references/safety-rules.md`, `skills/site-qa-audit/references/browser-guard.md`).

## Требования
**Функциональные**
- F1. `README.en.md` повторяет структуру верха P029 (те же блоки и порядок), объём ≤ 120 строк.
- F2. Все команды и пути — побайтно как в README.md (команды не переводятся).
- F3. Раздел Limitations обязателен и содержит языковую пометку; слово «English report» и примеры с ним не используются до P053.
- F4. Переключатель — первая строка после заголовка в обоих файлах.
- F5. Метка `<!-- readme-sync: YYYY-MM-DD -->` в обоих файлах; правило validate — только WARN.
- F6. Раздел Safety (3–5 строк) — для заявок в каталоги (P018).

**Нефункциональные**
- Качество перевода: машинный перевод + вычитка владельцем; термины — единый глоссарий из 10–15 слов (skill, plugin, marketplace, dry-run, finding, draft issue, triage, effort) в начале работы [оценка].
- Доступность: alt-тексты медиа на английском.
- i18n: только корневой README; документация скилов остаётся на русском (решение владельца).
- Совместимость: изменение validate не ломает существующие проверки и работает на Python 3.8+ (как весь `skillsrepo.py`, `tools/lib/skillsrepo.py:8`).

- `docs/media/*` — медиа P030 без изменений.
- `CHANGELOG.md` — запись.

## Риски и меры
- Расхождение RU и EN → метка `readme-sync` и WARN в validate; правило «правка верха README — правка обеих версий в одном коммите» в `CONVENTIONS.md`.
- Обещание английских отчётов до P053 → F3; при выходе P053 пометка меняется в том же релизе.
- Плохой машинный перевод отпугнёт носителей → вычитка, глоссарий, проверка двумя англоязычными разработчиками до подачи P018/P019.
- Англоязычный трафик упрётся в русский интерфейс скилов → честная пометка; решение «EN-запуск после P053 или сразу» — за оркестратором (К1).
