# P029. Переделать README в витрину: ценность в одной фразе, GIF, установка в три строки
Приоритет: P0 · Горизонт: now · Предпосылки: P030 · Связанные: P033 (делается внутри этого изменения), P028, P017, P069, P032, P059, P070, P054 · Макет: не предусмотрен (дизайн выключен выбором, у продукта нет UI)

Обоснование — P029 в реестре, раздел 10 стратегии. Здесь — только как сделать.

## Проблема
- Первая строка README — «Личная коллекция скилов для Claude Code…» (`README.md:3`) [факт]: посетитель не узнаёт, какую задачу решает продукт и для кого.
- Первое, что видно после заголовка, — таблица из четырёх описаний по 300–600 знаков (`README.md:12-15`), затем раздел установки со ссылками на три INSTALL.md (`README.md:20`) [факт].
- Команды установки есть (`README.md:27-28`), но рядом нет требований и предупреждения о ручном `npm install` после каждого обновления site-qa-audit (оно ниже, в таблице `README.md:42-46`) [факт].
- В `README.md:20` нет ссылки на `skills/product-strategy/INSTALL.md`, хотя файл есть [факт: ls, 2026-10-10].
- Половина README — разделы для разработчика скилов (симлинки, новый скил, validate, структура: `README.md:62-115`) [факт].

## Цель и метрики успеха
- **Основная:** 3 из 3 человек вне проекта после просмотра верхнего экрана README (до таблицы) отвечают на вопросы «что делает проект», «какой скил мне подходит», «как поставить» без подсказок [оценка; cheap_test реестра].
- **Исход:** конверсия «просмотр → звезда или клон» (`stars` и `clones.uniques` к `views.uniques` за 14 дней, снимки P043) растёт на +1..3 п. п. к базе до изменения [ДОПУЩЕНИЕ: из реестра; база не измерялась].
- **Вспомогательные:** доля посетителей, открывших quickstart или INSTALL (popular paths P043: `…/skills/<скил>/README.md`, `…/INSTALL.md`) [оценка].
- **Защитные:** `tools/validate.sh` без ошибок (таблица скилов и ссылки на месте, `tools/lib/skillsrepo.py:314`); ни одного утверждения сверх лицензии (сверка с `LICENSE`); вопросов «как установить» в Issues не больше, чем до изменения.

## Решение
Новый порядок README (RU; английская версия с тем же верхом — P069):

1. **Заголовок + фраза ценности** (одна, решается один раз вместе с P028 и переиспользуется в P017, P054, P069). Черновик-вариант для обсуждения: «Скилы для Claude Code, которые проверяют сайты и Android-приложения, выбирают модель под задачу и пишут стратегию продукта по репозиторию» [черновик]. Под ней — строка-переключатель `RU · EN` (ссылка на `README.en.md`, P069).
2. **Медиа:** один крупный GIF site-qa-audit (из P030) с подписью «что показано».
3. **Установка в три строки:**
   ```text
   /plugin marketplace add OrionFLASH/claude-code-skills
   /plugin install <имя-скила>@claude-code-skills
   /reload-plugins
   ```
   (третья строка — из `README.md:33`: новая версия и хуки видны только в новой сессии или после `/reload-plugins`).
4. **Блок «Кому подходит, что потребуется, сколько стоит прогон, лицензия»** — спецификация P033, вставляется здесь же, в одном изменении (конфликт К4 в `research/gap-audit.md`).
5. **Четыре карточки скилов** (по одной на скил, порядок — сначала самый лёгкий вход): что даёт (1 фраза), медиа (P030), пример промпта (из README скилов, например `skills/site-qa-audit/README.md:69`), сколько займёт первый результат (из P032), ссылки «Быстрый старт» (P032) и «Установка» (INSTALL.md скила, все четыре, включая product-strategy).
6. **Таблица скилов** — как сейчас, между маркерами `<!-- skills-table:start -->` / `<!-- skills-table:end -->` (`README.md:9`, `:16`): её перезаписывает `sync` (`tools/lib/skillsrepo.py:166`, `:190-197`), поэтому вручную не править и маркеры не трогать.
7. **Обновление и хуки** — существующие разделы `README.md:31-60` без изменений по смыслу.
8. **Лицензия** — существующий раздел `README.md:79-89` (краткая версия уже в блоке P033).
9. **Для разработчиков** — свернуть в конец разделы «Симлинками», «Новый скил», «Проверка перед коммитом», «Структура» (`README.md:62-115`); бейдж CI — после P059.

**Не входит:** переименование репозитория и маркетплейса (P028, отдельное решение до подачи в каталоги, конфликт К3); английская версия (P069); изменение описаний в `plugin.json` и `marketplace.json` (P054); темы и описание репозитория на GitHub (P017); новый корневой INSTALL.md.

5. Как читатель с мобильного, я хочу, чтобы верх README читался без горизонтальной прокрутки.
   - Given README в мобильном вебе GitHub; When открываю; Then блок установки и блок P033 — короткие строки, без широких таблиц в первом экране (таблица P033 — не больше 3 колонок).

- F1. Первый экран (до таблицы скилов): заголовок, фраза ценности ≤ 160 знаков, переключатель языка, один GIF, установка, блок P033.

- F3. Маркеры таблицы `README.md:9`, `:16` сохраняются; строки `](skills/<имя>/)` остаются в таблице (их ищет validate, `tools/lib/skillsrepo.py:314`).
- F4. Примеры промптов копируются из README скилов без изменений смысла; примеры с «English report» не выносить наверх, пока отчёты не переключаются на английский (`skills/site-qa-audit/README.md:73` обещает английский отчёт, а `skills/site-qa-audit/scripts/build_report.py:233` и соседние строки пишут русские заголовки; язык только записывается в конфиг — `skills/site-qa-audit/scripts/intake.py:230-231`).

**Нефункциональные**
- Доступность: alt-текст у медиа; заголовки по уровням (H1 → H2 → H3); ссылки с понятным текстом, без «здесь».
- Вес первого экрана — один GIF ≤ 1,5 МБ (остальные медиа — в карточках ниже).
- i18n: README на русском; переключатель на `README.en.md` (P069).
- Приватность: без личных путей, e-mail и имён, кроме ника автора, уже указанного в `LICENSE:1`.
